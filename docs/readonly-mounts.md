# Подключение только для чтения

Откройте контейнер в панели и выберите **Tools → Mount read-only…**.
Укажите допустимый размер временного кеша и, если нужен, пароль архива.
В **Read-only mounts…** доступны путь подключения, открытие папки и отключение.
Навигация панели не отключает уже подключённый контейнер.
Отключённую или неудачную запись можно убрать кнопкой **Убрать из списка**.
Файлы источника при этом сохраняются.
Имена в подключении различаются регистром: например, `libip6t_hl.so` и
`libip6t_HL.so` доступны как отдельные файлы.

Файлы с прямым доступом читаются из источника. Если для чтения требуется
извлечение, Sevenzip сначала запросит подтверждение для конкретного файла.
Отмена ничего не извлекает. Для повторного чтения сохранённого файла из кеша
новое подтверждение не нужно; после освобождения кеша оно потребуется снова.
Если файл не помещается в выбранный кеш, увеличьте лимит при новом подключении.

Повреждённые или неполные данные не считаются проверенными. Если движок смог
получить пригодную для чтения часть незашифрованного файла, Sevenzip отдельно
предложит использовать непроверенный результат. Такое согласие не исправляет
данные, не заменяет пароль и не даёт доступа к отсутствующим частям.
Предупреждения и ошибки чтения остаются в сведениях о подключении.

Перед отключением закройте файлы во внешних приложениях. Если том занят,
Sevenzip сохраняет подключение и позволяет повторить попытку. Принудительное
отключение требует отдельного подтверждения и может прервать работу открытых
файлов. При закрытии окна с активными подключениями можно отключить их или
отменить закрытие.

Если системный помощник аварийно завершился, повторите отключение в списке
подключений. Sevenzip сохраняет сервер на время восстановления управления.

## Системные требования

- **macOS:** используется штатный SMB-клиент; отдельный драйвер не нужен.
- **Windows:** для свободного SMB-порта нужна Windows 11 24H2, Windows Server
  2025 или более новая версия. Подключение требует разрешения администратора
  с той же учётной записью, в которой запущен Sevenzip.
- **Linux:** нужны системная поддержка CIFS и `mount.cifs`, обычно из пакета
  `cifs-utils`. Если их нет, установите поддержку через менеджер пакетов своего
  дистрибутива. Для системного подключения также нужна авторизация администратора.
  Sevenzip использует доступный системный помощник авторизации и сообщает,
  если разрешение получить не удалось. Собственного драйвера файловой системы
  приложение не предоставляет и пакеты автоматически не устанавливает.

Источник доступен только для чтения. Учётные данные подключения создаются для
этого сеанса; пароль системного пользователя не используется как SMB-пароль.
Системная политика может запрещать необходимый режим SMB. Приложение не меняет
глобальные настройки безопасности ради подключения.

Непредставимые имена и ограничения конкретного движка могут препятствовать
подключению или чтению отдельных файлов. Сообщение об ошибке описывает причину;
обычный просмотр и извлечение через панель остаются отдельными операциями.
Проверенные платформы и границы свидетельств приведены в
[техническом аудите](upstream-port-audit/readonly-smb.md).
