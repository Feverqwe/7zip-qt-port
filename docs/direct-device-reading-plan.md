# Прямое чтение устройств: первая версия

Цель — открыть внешний диск с незашифрованным ext2/3/4 на macOS, Windows
и Linux, просмотреть папки и скопировать выбранные файлы на другой том.
Драйвер файловой системы и предварительное создание полного образа не нужны.
Источник доступен только на чтение; системное разрешение запрашивается через
платформенный механизм. Пользователь выбирает диск и раздел по понятному
названию, размеру и доступным сведениям о содержимом.

## Границы

Первая версия не записывает и не исправляет файловую систему, не разблокирует
LUKS/fscrypt и не собирает LVM/RAID. Повреждённые диски не считаются сценарием
восстановления данных. Распознавание ext4 не обещает поддержку всех сочетаний
его возможностей. Неподдерживаемое содержимое должно давать понятный отказ.

Занятый том нельзя незаметно принудительно отключать. Прямое чтение одновременно
изменяемого раздела не даёт согласованного снимка. Там, где ОС уже предоставляет
доступ к папкам раздела, доступен обычный файловый сценарий.

## Существенные итерации

После каждой завершённой итерации — адресная проверка и отдельный коммит.

1. **Поток → раздел → файлы.** Использовать штатные GPT/MBR/Ext-обработчики
   7-Zip и ограниченные потоки. Проверить выбор раздела, извлечение, отмену,
   ошибки чтения и границы источника на изолированных образцах.
2. **Платформенный доступ.** Обнаруживать внешние устройства, получать
   read-only-дескриптор и размер. На macOS предоставить одноразовый помощник
   с системным запросом прав, работающий без Developer ID; на Windows — ограниченный процесс с повышением прав,
   на Linux — UDisks2. Привилегированный код открывает выбранное устройство,
   но не разбирает файловую систему и не записывает извлечённые файлы.
3. **Интегрированный пользовательский сценарий.** Подключить источник к
   существующим Agent/panel, просмотру, копированию, обновлению и завершению
   операций. Добавить выбор устройств/разделов, отметку «Только чтение»,
   сообщения об отказе в правах, неподдерживаемом разделе и отключении диска.
   Проверить состояния команд и переводы, нормальную/компактную геометрию.
4. **Платформенная приёмка.** Проверить доступные нативные сценарии и упаковку,
   сверить изменённый scope с upstream, описать ограничения. Отдельно сообщить
   о неподтверждённых реальных устройствах, системной авторизации и ОС;
   проверки потоков или макетов не заменяют их.

## Критерии

- Выбранный ext-раздел читается без копирования всего устройства.
- Содержимое скопированных файлов совпадает с исходным; Unicode и пробелы
  сохраняются. Конфликты имён обрабатываются существующим сценарием копирования.
- Источник не открывается для записи, и команды изменения недоступны.
- Отказ/отмена разрешения, отмена операции и потеря устройства завершаются
  корректно, оставляя приложение пригодным для следующей операции.
- Чтение не выходит за пределы разрешённого устройства и выбранного раздела.
- Обычные архивные сценарии сохраняются.

Проверки используют частные образцы. Доступ к настоящим пользовательским
дискам не нужен для автоматических regressions. Исходные владельцы,
адаптации и фактические свидетельства — в [аудите](upstream-port-audit/direct-devices.md).
