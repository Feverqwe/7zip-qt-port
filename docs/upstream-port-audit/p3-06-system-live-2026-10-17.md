## Native image correction

The real codec manager returns an icon-resource module filename. macOS previously
displayed that module's generic file icon for a pending own-app association,
instead of the application's native bundle icon. The existing macOS adapter now
supplies the bundle image through the optional native-image boundary already
used by Linux. QFileIconProvider resolves the actual application bundle; GUI-less
callers and non-bundle executables retain the fallback. No upstream portable
bundle-icon implementation exists: original 7zFM extracts indexed Win32 icons.
Windows retains that original loader. No new borrowed file, revision, library,
archive algorithm or native association writer is introduced.

The permanent `mac_system_page` regression uses the real native bundle-image
provider and an injected registration boundary. A nonempty module path reproduces
the failure. EN/RU × normal/compact covers Other→Own→Clear→Other, image restoration
and Cancel without a write. Its test bundle declares no document types and does
not register archive extensions. Both component wrappers and the Options verify
