## Исходная адаптация палитры

Источник: [ip7z/7zip](https://github.com/ip7z/7zip/tree/0766b733fe3e06dd2a7f9a3cfbf2108ac73abd17),

CHM 26.03; точный источник и контрольные суммы —
[help-provenance.json](../../third_party/7zip-help/help-provenance.json).

Сверены исходные ветви HtmlHelp/hh.exe, построение пути и темы, текущие
Qt-вызовы, загрузка HTML/CSS, переходы по ссылкам и история. Upstream
не содержит пригодной реализации адаптации CHM к палитре Qt.

Изменение ограничено `qthelpservices.cpp`: локальный наследник QTextBrowser
адаптирует цветовые токены загружаемого CSS к QPalette. Фон, текст,
таблицы и ссылки используют роли палитры; красные примеры/имена файлов и
зелёный footer сохраняют смысловой акцент с учётом светлого/тёмного фона.
PaletteChange обновляет CSS и страницу с сохранением прокрутки и истории.
Зависимости — существующие Qt Widgets/Gui, без нового движка отображения.

HTML/CSS на диске, их шрифты и разметка, исходный HelpUtils и его consumers
не меняются. Дополнительный upstream-код не копировался, пропущенных исходных
ветвей в изменяемом scope нет. Замена Win32 CHM на Qt остаётся ранее
зафиксированной платформенной адаптацией; исходный baseline сохранён.

Проверки: локальная macOS arm64, Qt 6.12; сборка `sevenzip_desktop`,

## Оформление таблиц и команд (2026-10-17)

По запросу пользователя добавлен небольшой CSS-слой поверх исходного стиля:
общая тонкая сетка таблиц, увеличенные отступы ячеек, сохранение шапки и
исходных выравниваний; моноширинные команды на подложке с сохранением
исходных строк и горизонтальной прокруткой. Остальные шрифты и структура страниц сохраняются.
Слой применяется внутри `HelpBrowser::themedStyle`; исходные файлы CHM,
baseline, HelpUtils, callers и нормализация ссылок не меняются.
Нового upstream-кода и зависимостей нет: это запрошенная Qt presentation
адаптация поверх исходного CSS, который уже содержит table/th/td/pre rules.

Сверены целиком исходный CSS, страницы форматов и синтаксиса, текущие
загрузка/перезагрузка stylesheet и навигация. Используется только
[поддерживаемый CSS Qt](https://doc.qt.io/qt-6/richtext-html-subset.html).
В частности, padding предназначен для ячеек; его поддержка для pre не
предполагается. Сохраняется режим `white-space: pre`: попытка использовать
`pre-wrap` добавляла в Qt лишние пустые строки и была отклонена после
сравнения полного текста с отображением исходной страницы.
Шрифт кода применяется также к вложенным ссылкам/элементам.
Подложки и границы выводятся из цветов Base/Text: нативная macOS AlternateBase
может давать слишком светлую подложку для цветных примеров в тёмной теме.

Проверки расширяют существующий сценарий палитры реальными страницами
синтаксиса на 760×560/420×300. Он проверяет читаемые foreground/background,
содержимое команд и сохранение навигации; точные CSS-константы не фиксируются
тестом. Widget JSON и снимки справки используются для оценки таблиц,
подложек и доступности footer. Дополнительная регрессия сравнивает полный
текст оригинального и оформленного QTextBrowser для синтаксиса, Add-примеров
и `method.htm#SevenZipYV/#MemUse`, включая вложенные таблицы и отступы.
Она воспроизвела лишние пустые строки до исправления; контраст текста
примеров и подложки проверяется независимо от точных цветов палитры.

macOS arm64 / Qt 6.12: сборка `sevenzip_desktop`, `help_source_tests`,
`help_ui_tests` успешна, focused `help_source|help_ui` — PASS (2/2).
Нативный Cocoa-прогон сценариев палитры/EN-RU геометрии и четырёх переходов
мышью/Return — PASS. Просмотрены текущие снимки таблиц и синтаксиса на обоих
размерах в заданных светлой/тёмной QPalette; это не проверка системного
переключения темы. Текущие JSON/PNG review находятся в `build/dev/help-code-review/`.
Windows/Linux и пиксельная идентичность Windows CHM не проверялись.
После коррекции блоков повторены focused `help_source|help_ui` — PASS (2/2)

### Колонки параметров

Сверены таблицы `method.htm` и остальные абсолютные/процентные width-атрибуты
исходной справки. У первой колонки таблицы 7z задано 80 px: с текущим шрифтом
и отступами Qt разбивал имя параметра на несколько строк даже в обычном окне.
В Qt presentation после загрузки документа абсолютные ограничения колонок
заменяются автоматическими; их содержимое и шапка сохраняют целые строки.
Размеры рассчитывает штатный QTextTable layout. Описания по-прежнему
переносятся, процентные ограничения и исходные HTML не меняются.
В компактном окне таблица может прокручиваться горизонтально.

`tableParameterNamesStayReadable` воспроизвёл перенос имени MethodID до
исправления. После исправления проверяются целая строка параметра/заголовка
и доступность последней колонки при 760×560/420×300.
macOS arm64 / Qt 6.12: сборка приложения и двух Help-targets успешна,
focused `help_source|help_ui` — PASS (2/2); нативные Cocoa-сценарии таблицы,
блоков кода и палитры — PASS. Текущие снимки и widget JSON:
`build/dev/help-table-review/`. Windows/Linux не проверены.
