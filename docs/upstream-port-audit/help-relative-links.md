# Относительные ссылки между разделами справки

Дата: 2026-10-17.

Источник: [ip7z/7zip](https://github.com/ip7z/7zip/tree/0766b733fe3e06dd2a7f9a3cfbf2108ac73abd17),
commit `0766b733fe3e06dd2a7f9a3cfbf2108ac73abd17`,
`CPP/7zip/UI/FileManager/HelpUtils.cpp/.h`, `ShowHelpWindow`:
построение пути CHM и делегирование отображения HtmlHelp/hh.exe.
Официальные страницы 26.03 и их контрольные суммы сохранены в
[provenance](../../resources/7zip/help-provenance.json).

Сверены исходный HelpUtils, текущая загрузка темы, CSS, обработчик ссылок,
история QTextBrowser и ссылки исходных HTML. В `fm/plugins/7-zip/add.htm`
ссылки на `cmdline/switches/method.htm` и `sfx.htm` содержат четыре `../`
при трёх уровнях вложенности. Обычное разрешение URL выходит за префикс
ресурсов и открывает пустую страницу. Проверка всех локальных href
показала только эти два выхода; оба целевых раздела присутствуют.

Адаптация ограничена Qt-обработчиком ссылок в `qthelpservices.cpp`:
относительные адреса разрешаются в отдельном пространстве корня справки,
после чего добавляется префикс Qt-ресурсов или локального каталога.
Лишние родительские сегменты останавливаются у корня справки.
Фрагменты и query сохраняются, регистр путей соответствует CHM.
Для нормализации используется QUrl, отдельный алгоритм разбора путей
не вводится. Qt заменяет нативный CHM viewer; upstream не содержит
пригодной реализации этого Qt boundary.

Исходные HTML/CSS, HelpUtils и его callers не меняются, новый upstream-код
не копируется, baseline и прежние пропуски Win32 presentation сохранены.
Регрессия использует настоящие ссылки из документа, проверяет содержимое
обоих целевых разделов, возврат с исходным якорем и переход вперёд.
Локальная macOS arm64 / Qt 6.12: сборка `sevenzip_desktop`,
`help_source_tests`, `help_ui_tests` успешна; `help_source` и `help_ui` — PASS (2/2).
Изменение не затрагивает layout/тексты/видимость; снимки не требуются.
Проверки выполняются отдельно от source comparison; Windows/Linux и
поведение оригинального Windows HtmlHelp на этих ссылках не проверены.
