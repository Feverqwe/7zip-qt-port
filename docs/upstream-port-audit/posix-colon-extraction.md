# POSIX filenames with colons during extraction — 2026-10-19

Source reference: <https://github.com/ip7z/7zip.git>, commit
`9128b80e3a471108678e2b3ec3c985861c8d7b0f`. Existing adapted path modules
retain their recorded mixed baseline; no new upstream bodies are copied.

`Correct_PathPart`, `Correct_FsPath`, `MakePathFromParts`) and the source
`CArchiveExtractCallback::CorrectPathParts` / `GetExtractStream` callers.

The port already preserves these branches; its additional Qt destination policy
incorrectly rejected colons on every platform after source path correction.
