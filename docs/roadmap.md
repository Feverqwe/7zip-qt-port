# Development roadmap

- [x] Independent UI repository and sibling official 7-Zip checkout.
- [x] Qt Widgets window scaffold and repeatable CMake presets.
- [x] `ArchiveBackend` contract and official `7zz` process adapter.
- [x] Open `.7z` and `.zip` archives and display entries.
- [x] Extract and create `.7z` and `.zip` archives with progress, cancel, and errors.
- [ ] Improve progress detail and add an operation log for large archives.
- [ ] Add a combined file and folder source picker and archive navigation.
- [ ] Password handling and archive testing.
- [ ] File navigation, keyboard shortcuts, drag and drop, and platform integration.
- [ ] Windows, macOS, and Linux builds and packaging.

Advance this list only when an item works and its relevant checks pass. Add tasks as product decisions are made.
