# Сверка с Windows 7zFM

Ориентир — `../7zip-upstream/CPP/7zip/UI/FileManager/`. Это исходники Windows-приложения, а не код, который собирается в Qt-проекте. Состояния ниже относятся к текущему Qt-окну; они не означают проверку на Windows или Linux.

| Узел 7zFM | Исходник | Состояние Qt и точное расхождение |
| --- | --- | --- |
| Две группы панели Add/Extract/Test и Copy/Move/Delete/Info | `App.cpp`, `g_ArchiveButtons`, `g_StandardButtons`, `ReloadToolbars()` | Порядок, разделитель, цветные символы и подписи перенесены. Символы рисуются средствами Qt; bitmap-ресурсы upstream не включены в проект. |
| Настройки панели: две группы, крупные кнопки, подписи | `App.h`, `ReadToolbar()`, `SaveToolbar()`; `resource.rc`, View → Toolbars | Четыре переключателя в меню «Вид», сохранение в локальном INI через `QSettings`. |
| Заголовок списка и видимые свойства | `PanelItems.cpp`, `GetColumnVisible()`, `ShowColumnsContextMenu()` | Имя, размер, сжатый размер и изменение показаны без служебного полного пути и номеров строк; «Сжатый» скрыт в обычной папке. Видимость доступных столбцов настраивается из заголовка и сохраняется. Набор свойств пока фиксирован, а в 7zFM зависит от папки и формата. |
| Сравнение и сортировка | `PanelSort.cpp`, `CompareFileNames_ForFolderList()`; `resource.rc`, View → Arrange | Числовые части имени сравниваются как в 7zFM: `2.txt` идёт перед `10.txt`; сравнение без учёта регистра. Меню и Ctrl+F3–F7 выбирают имя, тип, дату, размер или исходный порядок. Для архива исходный порядок берётся из ответа backend, для обычной папки — из перечисления ОС. Папки остаются перед файлами; точное сравнение всех свойств и режим сортировки двух панелей 7zFM ещё не перенесены. |
| Контекстное меню списка | `PanelMenu.cpp`, `OnContextMenu()`, `CreateFileMenu()` | Состав зависит от выделения и режима каталога/архива; добавлены команды фона и свойства одного объекта. Нет расширений оболочки Windows, 7-Zip submenu и полного набора операций. |
| Свойства выделения | `PanelMenu.cpp`, `Properties()` | Диалог одного файла или папки показывает имя, путь, тип и доступные размер/сжатый размер/дату. В 7zFM есть форматные и сырые свойства, а также сводка для нескольких объектов. |
| Клавиатура списка | `PanelKey.cpp`, `OnKeyDown()` | Enter, Backspace, F2, F5, F6, F7, Delete, Ctrl/Cmd+A, Ctrl+N, Alt+F12, Ctrl+F3–F7 и обновление работают в реализованных режимах. F3/F4 и часть команд редактирования ещё отсутствуют. |
| Главное меню | `resource.rc`; `MyLoadMenu.cpp`, `OnMenuActivating()` | Работают основные «Файл», «Правка», «Вид», «Избранное». Оригинал формирует File динамически и содержит больше команд: Open Inside/Outside, View/Edit, Split/Combine, CRC, Diff, Link и Alternate Streams; также есть Tools и Help. |
| Панели и режимы списка | `App.cpp`, `Panel.cpp`; `resource.rc`, View | Сейчас одна таблица подробностей. Две панели, крупные/мелкие значки, простой список и плоский просмотр отсутствуют. |
| Адрес и история | `Panel.cpp`, `PanelFolderChange.cpp`, `FoldersHistory()`; `ListViewDialog.rc` | Qt использует редактируемый выпадающий список с 20 посещёнными каталогами и корнями архивов, сохранённый в INI. Диалог Alt+F12 показывает эту историю, позволяет удалить записи и перейти к выбранной; история «Назад» отдельная. В 7zFM список истории содержит также внутренние папки архива, а диалог использует системный ListView. |
| Создание файла и выбор по маске/типу | `PanelOperations.cpp`, `CreateFile()`; `PanelSelect.cpp`, `SelectSpec()`/`SelectByType()`; `ComboDialog.rc` | Команда Ctrl+N создаёт пустой файл в обычной папке через редактируемый диалог; в архиве отключена. «Правка» выделяет или снимает выделение по нечувствительной к регистру маске `*`/`?` либо по расширению текущего файла (для папки — все папки). Qt-диалог повторяет поля ComboDialog, но не хранит историю введённых масок. |
| Закладки | `PanelFolderChange.cpp`, `SetBookmark()`/`OpenBookmark()`; `PanelKey.cpp`; `resource.rc`, Favorites | Меню «Избранное» хранит 10 слотов в локальном INI, включая текущую папку архива. Alt+Shift+цифра записывает слот, Alt+цифра открывает его при фокусе таблицы. На Windows 7zFM также поддерживает правый Ctrl с цифрой; здесь используется Alt. |
| Архивные операции | `App.cpp`, `Panel.cpp`, диалоги FileManager | Qt поддерживает создание, добавление в открытый архив, извлечение, тест и основные изменения через `ArchiveBackend`. В Windows сценарии выбора файлов и форматы диалогов шире; здесь действуют ограничения из README. |
| Диалог Copy/Move | `CopyDialog.rc`, `CopyDialog.cpp`; `App.cpp`, `Copy()` | F5/F6 для файловой системы открывают общий диалог с редактируемой историей назначения, кнопкой выбора папки и именами выбранных объектов. История до 20 путей хранится в локальном INI. Перенос внутри архивов и между панелями пока отсутствует. |

## Следующие крупные блоки

1. Перед переносом двухпанельного режима выделить модель панели и навигации из `MainWindow`, затем повторить поведение F9 и операций между панелями из `App.cpp`.
2. Добавить режимы просмотра, сортировку по свойствам и динамические столбцы по `PanelItems.cpp`, `PanelSort.cpp` и `resource.rc`.
3. Переносить команды File и контекстного меню по одной с их состояниями доступности из `PanelMenu.cpp` и `MyLoadMenu.cpp`. Для Open Inside/Outside и View/Edit сначала определить безопасную временную распаковку и время жизни файлов.
4. Расширить постоянную историю адресов, диалоги свойств и настроек. Платформенные отличия системных меню и интеграции проверять отдельно на Windows, macOS и Linux.
