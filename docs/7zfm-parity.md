# Поведение и платформенные отличия

Windows 7zFM — исходный ориентир для команд, структуры диалогов и workflow.
Qt заменяет presentation и платформенные services; архивные операции используют
официальный движок. [Итоговая приёмка](ux-port-audit.md) описывает проверенный
объём и оставшиеся границы свидетельств.

## Основные сценарии

Две панели поддерживают файловую и архивную навигацию, вложенные архивы,
историю, избранное, режимы списка, сортировку и выделение. Copy/Move,
Create/Rename/Delete, Split/Combine, Properties, Hash/Test и Benchmark
используют исходных владельцев операций. View/Edit/Diff открывают внешние
приложения; запись изменённого файла обратно в архив зависит от возможностей
формата и доступности записи всей цепочки вложенных архивов.

Add и Extract поддерживают исходные параметры, запросы пароля, перезапись,
тома и SFX в пределах возможностей официального runtime. Ошибка или отмена
извлечения может оставить уже записанные файлы. Read-only формат, недоступная
возможность ОС и неподдерживаемая операция должны давать соответствующий отказ.

Относительные имена с `./`, в том числе в CPIO payload установщиков, допускаются
при распаковке. Защита каталога назначения и проверка конфликтов имён сохраняются.
При копировании содержимого открытой архивной папки её исходный префикс может
содержать `..`: проверяется путь относительно этой папки. Компоненты `..`,
оставшиеся в пути назначения, отклоняются.
[Сверка исходников и проверки](upstream-port-audit/dot-extraction-paths.md).

Options сохраняет исходные группы настроек и Apply/Cancel. Системная
регистрация, native контекстное меню и обработка открытия документов зависят
от платформы, прав и фактической установки приложения.
Подпись Zone.Id на вкладке «7-Zip» переносится только при нехватке места в строке.
[Проверка геометрии диалогов](upstream-port-audit/dialog-layout-review.md).

Дополнительные параметры создания архива сохраняют исходные группы NTFS/времени
и места скрытых опций. Qt переносит подпись точности по доступной ширине;
флажки явного задания значений сохраняют двоеточие рядом с индикатором при
разной высоте строк. [Сверка и проверки](upstream-port-audit/compress-options-layout.md).

По запросу пользователя добавлена команда «Файл → Открыть архив…» с системным
выбором файла и Cmd+O на macOS / Ctrl+O на Windows и Linux. Это расширение меню
оригинального 7zFM. Отмена сохраняет текущую папку; выбранный файл открывается
существующим архивным workflow.

По запросу пользователя подписи открытия в Qt-меню уточняют назначение:
открытие как архива в текущей панели, запуск внешнего приложения и открытие
архива в новом окне. Специальные режимы сопровождаются пояснениями.
Расположение пунктов, группы, сочетания клавиш и поведение исходного 7zFM
сохранены. Это адаптация подписей в приложении; меню расширения Windows Explorer
сохраняет исходные названия.

## Дополнительные форматы

Обычные Brotli-файлы `.br` и `.brotli` доступны для просмотра, проверки и
распаковки. Имя извлекаемого файла определяется именем внешнего файла без
суффикса Brotli. Создание и изменение не поддерживаются. Нужен поставляемый
динамический runtime с модулем Brotli; это расширение сверх исходного 7zFM.
[Происхождение, ограничения и проверки](upstream-port-audit/brotli.md).

Образы exFAT и согласованные TexFAT доступны для просмотра и извлечения без
изменения исходного образа. TexFAT с признаками незавершённой операции или ошибки
носителя отклоняется. Запись и восстановление не поддерживаются. Это расширение
сверх исходного 7zFM; требуется поставляемый динамический runtime с модулем exFAT.
[Происхождение и проверки](upstream-port-audit/exfat-linux.md).

## Необходимые платформенные адаптации

| Область | Отличие и граница |
| --- | --- |
| Диалоги | Native fonts, button minima, chrome и scaling Qt могут менять размеры; группировка, состояния и доступность проверяются по [UI contracts](ui-layout-contracts.md) |
| Клавиатура и меню | Platform key mapping, Cocoa global menu и физический Control требуют native проверок; offscreen-проверка их не заменяет |
| Выбор файлов и системные окна | Native OS panels проверяются отдельно от widget dialogs |
| Файловая система | Links, junctions, ADS, security metadata и native namespaces зависят от ОС, файловой системы и прав |
| Associations | Изменения регистрации не подтверждают защищённый OS-выбор приложения по умолчанию; Apply/Cancel и отказы проверяются отдельно |
| External codecs и SFX | Нужен совместимый официальный runtime; standalone `7zz` имеет иной набор возможностей, см. [настройку runtime](development.md) |
| Поставка | Состав runtime и подпись описаны в [packaging/CI](ci.md); локальная relocation-проверка не подтверждает clean-OS установку |
| Имя приложения | Qt-приложение называется Sevenzip; на macOS поставляется как `Sevenzip.app`. Настройки хранятся под именем Sevenzip отдельно от исходного 7zFM |
