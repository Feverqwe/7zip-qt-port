# Поведение и платформенные отличия

Windows 7zFM — исходный ориентир для команд, структуры диалогов и workflow.
Qt заменяет presentation и платформенные services; архивные операции используют
официальный движок. [Итоговая приёмка](ux-port-audit.md) описывает проверенный
объём и оставшиеся границы свидетельств.

## Основные сценарии

ISO9660 читает тома с блоками 512/1024/2048 байт, XAR и составные каталоги;
повреждённые maps и interleaving дают явную ошибку чтения. Потоки файлов и
El Torito images независимы. Исходные archive names и boot namespace сохранены.
Отдельный модуль добавляет Linux Rock Ridge names/links, POSIX metadata,
continuations, relocated directories, выбор RR перед Joliet, zisofs и High Sierra.
Joliet names и RR fallback используют Linux Unicode/суффиксные правила;
CLI open-properties доступны для normal/Acorn/raw mapping и UTF-8/CP437.
Поддержано чтение глубоких ISO-деревьев и извлечение отдельного вложенного
файла в поток.
[Scope и проверки](upstream-port-audit/isofs-linux.md); полная актуализация
ISO9660 по Linux ещё не завершена.

SquashFS сообщает реальные inode identity и symlink targets стандартному
механизму 7-Zip. При process extraction действует существующий запрет links:
набор со ссылкой отклоняется, выбранные обычные файлы извлекаются. Source
extraction использует исходный callback и native OS link services; возможность
создания ссылок зависит от платформы и прав. [Scope и проверки SquashFS](upstream-port-audit/squashfs-linux.md).

Чтение HFS+/HFSX дополнено исправлениями по Linux: fragmented/preallocated
forks, boot blocks и wrappers, проверки повреждённых metadata и независимые
потоки. Отдельный read-only модуль добавляет Linux Unicode composition/casefold,
hardlink backing data, Linux permission defaults, BSD flags и FinderInfo streams.
Даты следуют Linux диапазону 1970–2106; специальные inode сообщают device metadata.
Тот же модуль читает plain classic HFS, включая resource forks, type/creator
metadata и non-power-of-two allocation blocks.
[Scope и проверки](upstream-port-audit/hfs-linux.md); полная актуализация
формата ещё не завершена.

File → Open device добавляет переносимый выбор внешнего устройства и раздела
для прямого чтения ext, сохраняя обычные тома и открытие архивов. Это расширение
исходного Windows device namespace: системные права получает узкий native service,
а просмотр и копирование остаются в source Agent/panel без повышения прав GUI.
Занятые устройства не размонтируются принудительно; источник помечен «Только чтение».
Для читаемого раздела с незавершённым recovery или readonly-compatible
ограничениями предлагается явное чтение с ограничениями:
Cancel по умолчанию, пояснение возможной несогласованности файлов и постоянная
отметка выбранного режима. Запись на источник, восстановление журнала и
очистка осиротевших файлов отсутствуют; согласие не заменяет отсутствующий decoder.
Тот же выбор применяется к образам ext с незавершённым recovery, потерянными
файлами, нечистым состоянием или непроверенными read-only признаками, а также
к образам exFAT/TexFAT, когда reader сообщает dirty/media
состояние, и к HFS/HFS+ с unclean состоянием, недостоверной статистикой свободного
места или незащищённой HFS оболочкой. Недостоверное значение свободного места
не публикуется. Для NTFS dirty или неизвестное состояние тома также требует
явного выбора ограниченного чтения; журнал не воспроизводится. При недоступных
reparse-метаданных читаемые потоки DATA объектов неустановленного типа предлагаются
с явным обозначением этого режима. Непрочитанное содержимое известной ссылки
остаётся ошибкой файла; остальные доступные файлы и потоки можно копировать.
Ошибки расширенных атрибутов NTFS также допускают ограниченное открытие с
предупреждением об отсутствующих EA/WSL metadata и доступом к читаемому DATA.
При неполных DATA mappings доступны известные участки и независимые потоки;
полное копирование с недостающими байтами сообщает ошибку. Непроверенное чтение
локальных DATA при недоступном attribute list требует того же явного выбора.
Папка показывается после подтверждения и сохраняет видимую отметку
ограничений; новое открытие запрашивает согласие снова.
Сценарий не требует драйвера ФС или полного образа. Платформенные зависимости,
границы ext и фактическая приёмка — в [аудите](upstream-port-audit/direct-devices.md).
При копировании и извлечении POSIX сохраняет двоеточия в обычных именах файлов;
Windows использует исходную коррекцию имён и отдельные правила ADS.
[Проверенный сценарий](upstream-port-audit/posix-colon-extraction.md) включает
timestamp-файл внутри ext4, открытого без journal replay.
Если gzip не хранит имя файла, Copy/Extract используют исходные правила 7-Zip
для имени по архиву; это распространяется и на gzip внутри read-only ext4.
[Scope и проверки](upstream-port-audit/nameless-stream-extraction.md).

По согласованному редизайну форма имени/маски и диагностические сообщения
используют общую Qt-компоновку с нативными кнопками и проектными отступами.
Короткая форма открывается по высоте содержимого; отчёт отдаёт свободное место
списку. Это намеренное отклонение от исходной геометрии Windows, с сохранением
значений, отмены, строк сообщений и modal results.
[Область и проверки](upstream-port-audit/ui-redesign.md).

Встроенный выбор длинных путей использует ту же рамку, подписи пути/типа и
основную кнопку «Выбрать папку», «Открыть» или «Сохранить» по текущему режиму.
Обычный системный выбор файлов сохраняется. В очистке временных файлов
заблокированный список с единственным фильтром заменён сводкой выделения и
объяснением защиты. Все шесть столбцов, навигация, подтверждения и ограничения
удаления сохраняются.

Графика команд toolbar и навигации использует локальные контурные значки Lucide
по концепту, с цветами текущей палитры и масштабом экрана. Тот же набор применяется
к переходу вверх, созданию папки и действиям очистки временных файлов.
Для команд главной панели обычный размер — 16×16 логических единиц, увеличенный —
24×24; исходные размеры bitmap canvas 24×24/48×36 к векторным символам не применяются.
Верхняя область главного окна получает интервалы свободного концепта, обычный
системный шрифт подписей и отдельную строку навигации. На macOS кнопка перехода
к родителю использует нативную кнопку вместо квадратной tool-кнопки; она вызывает
прежнюю команду и отражает её доступность. Нативные цвета, заголовок окна,
реальные пути и системные файловые значки сохраняются.
Нативные файловые/системные значки и изображение приложения сохранены.
Команды, состояния, tooltips и сочетания клавиш этим изменением не меняются.

На macOS контекстные формы с родителем открываются как нативные sheets и
блокируют своё окно. Независимое окно остаётся доступным; вложенная отмена
сохраняет родительский черновик. Исходные синхронные результаты и модальность
прогресса сохраняются. Windows/Linux используют прежнее поведение.

Таблицы свойств и контрольных сумм используют ту же компоновку с Copy/Close.
Кнопка Copy копирует полные выбранные строки, а без выделения — весь отчёт;
исходное клавиатурное копирование и открытие полного значения сохранены.
Подробный текст показан системным моноширинным шрифтом с прежним размером,
обеими прокрутками и Copy/Close. В истории папок OK переименован в Open,
Cancel сохраняет исходную транзакцию истории. Это согласованные изменения
представления; генерация свойств, контрольных сумм и навигация не менялись.

Окно выполнения показывает ход операции, текущий путь, время и число файлов
перед подробной статистикой. Размеры, скорость и коэффициент сжатия доступны
через Details; скрытые счётчики продолжают обновляться. Ошибки и кнопки
управления остаются вне раскрываемого блока. Qt layouts заменяют исходную
геометрию OnSize; пауза, приоритет, подтверждение отмены, сообщения и завершение
сохраняют исходных владельцев и результаты.

Обе формы benchmark используют общую строку действий и копирование отчёта.
Обычный режим показывает все метрики в единой таблице, лог — под ней;
полный режим сохраняет исходный текстовый вывод. Текст не переносится и доступен
полностью через прокрутку и копирование. Close вызывает прежнее завершение с
ожиданием worker; Restart/Stop и изменение параметров сохраняют исходные сценарии.

Add/Extract упрощены по тому же плану: основные поля видны сразу, пароль
включается отдельно, остальные параметры раскрываются по запросу. В Add четыре
группы закрыты при первом показе, включая сжатие; у скрытых активных параметров
используется короткая отметка «Изменено». Длинные сводки архивных форм удалены.
Имя и редактируемая папка назначения разделены; «Обзор…» выбирает папку через
существующий native/custom folder picker, сохраняя имя и формат. Выбор формата
остаётся в форме, а история восстанавливает исходные имя/папку/формат. Это
согласованное изменение прежнего общего save picker.
Сворачивание не выключает настройки. Выключение защиты исключает
пароль из запроса, сохраняя черновик в открытой форме. Windows-only параметры
Shared/Security скрыты на POSIX. Исходные режимы, профили, ошибки и обработчики
операций сохранены. Это осознанное изменение структуры относительно Windows 7zFM.

Вложенные параметры формата используют ту же общую компоновку: сведения о формате
сверху, лёгкие группы ссылок/метаданных и времени, Save/Cancel/Help. Контролы
явного значения и исходные precision/default transitions сохранены. Пустые области
от неподдерживаемых полей не резервируются; отмена сохраняет черновик Add.

Короткие Copy/Move/Combine, Split, Password, Memory и Link используют общие
поля и строку завершения, нативные размеры кнопок и подписи по результату.
Overwrite сравнивает два файла рядом, сохраняя все исходные ответы; запрещённые
пакетные ответы скрываются по исходному условию. Memory показывает решение для
текущего архива перед изменением лимита следующих операций. Это согласованные
изменения представления; форматирование данных, проверки и результаты сохранены.

Разделитель двух панелей дополнен клавиатурным фокусом и управлением стрелками;
Return или двойной щелчок возвращает равные доли. Это согласованное расширение
исходного mouse-drag управления. Пропорция, ограничения и хранение позиции
используют прежнего владельца. Временный минимум Qt-содержимого не заменяет
выбранную пропорцию при переключении одной/двух панелей. Перетаскивание сохраняет
фокус в файловом списке; управление с клавиатуры оставляет его на разделителе.

Toolbar использует смешанное представление: текст рядом со значками Add/Extract
и только значки для остальных пяти команд. Подсказки содержат локализованное
название и действующее сочетание; кнопки доступны с клавиатуры. Существующие
настройки labels/size/групп сохраняются; labels теперь управляет подписями двух
основных действий. Команды, доступность и целевая панель остаются у CApp/CPanel.

File/View/context меню перегруппированы по согласованному концепту. Режимы
открытия и создание вынесены в подменю, редкие операции и системные расширения —
в «Дополнительно»/«Ещё», представление и сортировка — в отдельные подменю «Вида».
Полный исходный набор команд, алгоритмы хешей, состояния и диспетчер сохранены.
Подпись «Формат времени» постоянна; исходные текущие примеры и UTC остаются внутри.
Это намеренное изменение расположения относительно RC Windows 7zFM.

Основные сочетания Qt обновлены по [согласованной схеме](ui-shortcuts-design.md).
Команды файлового списка не перехватывают обычный ввод в редакторе имени,
строке пути или модальном окне. Меню, контекстные копии и toolbar показывают
актуальное основное назначение; исходные обработчики и проверки остаются прежними.
Редкие Shift/F-key/clipboard варианты сохраняются, конфликтующие назначения
синхронизации и закладки 2 доступны через варианты, указанные в схеме.

Язык интерфейса выбирается из каталогов Qt Linguist. Исходные языковые `.txt`
7-Zip заменены каталогами `.qm`; настройки English/Russian сохранены. Страница
языка сохраняет порядок элементов и поведение Apply/Cancel, а область сведений
показывает язык и локаль. Сведения о полноте перевода доступны в Qt Linguist.
[Область миграции и проверки](upstream-port-audit/qt-linguist.md).

About presents Sevenzip as an independent application, with its own name,
release and project link. A separate 7-Zip section retains the upstream version,
release date, copyright, license and homepage. The original About logo and
layout are replaced by this explicitly requested product identity.
[Source comparison and validation](upstream-port-audit/about-product-identity.md).
The redesigned frame uses shared spacing and Close with the original default
confirmation role. Help keeps the bundled HTML and existing navigation inside
the same shared frame; no article replacement or shortened topic list is added.

Контекстное меню сохраняет доступность команд выбранной панели при переходах
фокуса; после отмены подтверждения Drop команды снова доступны.
[Адаптация и проверки](upstream-port-audit/popup-command-state.md).

Pause сохраняется при смене асинхронной фазы архивной операции, включая
новый CLI-процесс, создание томов и удаление исходников после сжатия.
Continue возобновляет текущую фазу; ошибка управления поступает в существующий
канал диагностики и отмены.
[Адаптация и проверки](upstream-port-audit/qt-phase-controls.md).

Встроенная справка следует светлой или тёмной палитре приложения, включая
уже открытые разделы. Исходные страницы и навигация сохранены; адаптация
цветов заменяет фиксированное светлое оформление CHM.
[Границы адаптации и проверки](upstream-port-audit/help-theme.md).
Фон страницы совпадает с фоном окна справки. Подложки, ссылки и смысловые
акценты рассчитываются относительно текущей системной палитры; отметки файлов
и цвет удалённых элементов также адаптируются при её смене.
[Общая палитра](upstream-port-audit/adaptive-colors.md).
Таблицы и блоки команд оформлены для чтения: тонкая сетка, выделенная шапка,
свободнее ячейки и отдельная подложка команд. Исходные строки и отступы
команд сохраняются; длинные строки доступны через горизонтальную прокрутку.
Устаревшие фиксированные колонки таблиц подбираются по содержимому,
чтобы имена параметров не разрывались; узкое окно допускает прокрутку таблицы.
Относительные ссылки разрешаются внутри корня справки, включая переходы
из раздела добавления к описаниям Method и SFX с лишними `../` в исходном HTML.
[Сверка и регрессия](upstream-port-audit/help-relative-links.md).

В Small Icons подпись находится справа от значка. Длинные имена сокращаются
в пределах ячейки, высота строки учитывает размер шрифта.
В Large Icons подпись переносится под значком; размеры следуют шрифту и стилю
платформы. Для длинных имён отведены две строки и подсказка с полным путём.
Прокрутка к элементу направляется в текущий вид списка. Задержка выделения
наведением берётся из Windows или, на других ОС, из стиля Qt.
[Сверка исходников и геометрии](upstream-port-audit/small-icons-layout.md).
Блокировка списка отменяет ожидающее выделение наведением; после разблокировки
для него требуется новое движение мыши.
В альтернативном выделении обычная стрелка после Shift+стрелки перемещает
фокус без добавления следующего файла в отмеченные.
[Проверки отложенных событий](upstream-port-audit/qt-list-events.md).

Две панели поддерживают файловую и архивную навигацию, вложенные архивы,
историю, избранное, режимы списка, сортировку и выделение. Copy/Move,
Create/Rename/Delete, Split/Combine, Properties, Hash/Test и Benchmark
используют исходных владельцев операций. View/Edit/Diff открывают внешние
приложения; запись изменённого файла обратно в архив зависит от возможностей
формата и доступности записи всей цепочки вложенных архивов.

Add и Extract поддерживают исходные параметры, запросы пароля, перезапись,
тома и SFX в пределах возможностей официального runtime. Ошибка или отмена
извлечения может оставить уже записанные файлы. Read-only формат, недоступная
возможность ОС и неподдерживаемая операция должны давать соответствующий отказ.

В окне создания архива смена параметров сохраняет размер окна, границы колонок
и положение остальных полей. Скрытые настройки оставляют своё место; длинные
значения памяти переносятся внутри колонки. Ручное изменение окна и смена
языка/шрифта сохраняют адаптацию к доступному месту.
[Сверка и проверки](upstream-port-audit/add-dialog-stable-columns.md).

Относительные имена с `./`, в том числе в CPIO payload установщиков, допускаются
при распаковке. Защита каталога назначения и проверка конфликтов имён сохраняются.
При копировании содержимого открытой архивной папки её исходный префикс может
содержать `..`: проверяется путь относительно этой папки. Компоненты `..`,
оставшиеся в пути назначения, отклоняются.
[Сверка исходников и проверки](upstream-port-audit/dot-extraction-paths.md).

Оформление приложения можно оставить системным либо выбрать светлое/тёмное.
Это дополнение Qt-интерфейса: Apply/OK применяет и сохраняет выбор, Cancel
отбрасывает черновик. При следующем запуске выбор восстанавливается;
цвета по-прежнему предоставляет нативная палитра Qt.

Options сохраняет шесть исходных владельцев и показывает отдельные страницы
задач с боковой навигацией, которая переносится наверх в узком окне.
Сведения о переводе раскрываются по запросу. Форматы доступны в едином списке
с поиском по названию и расширению; массовый выбор охватывает весь список,
фильтрация не меняет выбор. Исходные состояния и поддерживаемый системный
охват ассоциаций доступны дополнительно. Черновик сохраняется при смене раздела,
Apply/Cancel и исходная обработка ошибок сохранены. Системная
регистрация, native контекстное меню и обработка открытия документов зависят
от платформы, прав и фактической установки приложения.
Неподдерживаемые платформой настройки и действия скрыты; доступные параметры
контекстного меню внутри приложения сохранены.
[Границы видимости настроек](upstream-port-audit/options-platform-visibility.md).
Подпись Zone.Id на вкладке «7-Zip» переносится только при нехватке места в строке.
[Проверка геометрии диалогов](upstream-port-audit/dialog-layout-review.md).

Дополнительные параметры создания архива сохраняют исходные группы NTFS/времени.
Окно подбирает начальный размер по видимым параметрам; скрытые группы и строки
не оставляют пустые области. Флажки явного задания подписаны «Задать» и поясняют
переопределение значения формата по умолчанию. Неподдерживаемое сохранение времени
доступа скрыто на POSIX. [Сверка и проверки](upstream-port-audit/compress-options-layout.md).

По запросу пользователя добавлена команда «Файл → Открыть архив…» с системным
выбором файла и Cmd+O на macOS / Ctrl+O на Windows и Linux. Это расширение меню
оригинального 7zFM. Отмена сохраняет текущую папку; выбранный файл открывается
существующим архивным workflow.

Один архив известного движку формата, перетащенный из внешнего файлового
менеджера на панель обычной папки, открывается в этой панели. Это запрошенное
отличие от 7zFM, предлагающего упаковку. Несколько файлов и обычные файлы
сохраняют действие добавления к архиву; перетаскивание в открытый архив,
внутренние переносы 7-Zip и меню правой/средней кнопки сохраняют исходное поведение.
Ошибка открытия архива показывается без предложения упаковать его заново.
[Сверка и проверки](upstream-port-audit/archive-drop-open.md).

По запросу пользователя подписи открытия в Qt-меню уточняют назначение:
открытие как архива в текущей панели, запуск внешнего приложения и открытие
архива в новом окне. Специальные режимы сопровождаются пояснениями.
Расположение пунктов, группы, сочетания клавиш и поведение исходного 7zFM
сохранены. Это адаптация подписей в приложении; меню расширения Windows Explorer
сохраняет исходные названия.

## Дополнительные форматы

Обычные Brotli-файлы `.br` и `.brotli` доступны для просмотра, проверки и
распаковки. Имя извлекаемого файла определяется именем внешнего файла без
суффикса Brotli. Создание и изменение не поддерживаются. Нужен поставляемый
динамический runtime с модулем Brotli; это расширение сверх исходного 7zFM.
[Происхождение, ограничения и проверки](upstream-port-audit/brotli.md).

Образы exFAT и согласованные TexFAT доступны для просмотра и извлечения без
изменения исходного образа. TexFAT с признаками незавершённой операции или ошибки
носителя отклоняется. Запись и восстановление не поддерживаются. Это расширение
сверх исходного 7zFM; требуется поставляемый динамический runtime с модулем exFAT.
[Происхождение и проверки](upstream-port-audit/exfat-linux.md).

Cramfs читается с расширенными указателями блоков, несжатыми блоками,
разделяемыми данными, sparse-областями и 512-байтным префиксом образа.
Полное обновлённое чтение доступно через поставляемый динамический runtime
с отдельным cramfs-модулем; standalone `7zz` сохраняет legacy reader.
[Происхождение и проверки](upstream-port-audit/cramfs-linux.md).

FAT поддерживает образы DOS 1.x и современные тома без boot signature,
восстановление длинных имён и Linux-совместимую обработку CP437/Unicode и дат.
Полное расширение доступно через динамический runtime с отдельным FAT-модулем;
standalone `7zz` сохраняет классический reader с общими исправлениями BPB/цепочек.
[Происхождение и проверки](upstream-port-audit/fat-linux.md).

NTFS читает sparse и initialized data, compressed файлы и тома с сектором
4 KiB с общими исправлениями обоих engines. Динамический runtime дополнительно
использует Linux LZNT1, включая нулевое заполнение коротких compressed frames;
standalone сохраняет классический декодер. Динамический runtime также читает
WOF LZX/XPRESS и MFT с дополнительными extents из attribute lists; standalone
явно отклоняет эти расширения. EFS возвращает явный отказ, как в Linux.
Нулевой WOF-хвост после initialized size читается независимо от доступности
сжатого ADS. Ошибки initialized data остаются явными; unknown WOF formats
не декодируются, как в Linux NTFS3. Запись в NTFS не добавлялась.
Process extraction выбранного обычного файла исключает невыбранные ADS;
WOF извлекается в декодированный файл без попытки записать служебный
`WofCompressedData` в Windows. Явное чтение raw ADS остаётся отдельной операцией.
[Scope и проверки](upstream-port-audit/ntfs-linux.md).

Динамический ext-модуль проверяет builtin signatures fs-verity с явно переданными
сертификатами доверия. Настройки доступны через стандартные свойства SDK и CLI;
отдельного редактора сертификатов в GUI нет. Системные trust stores не используются.
Standalone `7zz` отклоняет verity-marked streams. [Политика, параметры и границы
проверок](upstream-port-audit/ext-linux.md#builtin-signatures-and-explicit-archive-trust).

Образы EROFS доступны для просмотра, проверки и извлечения, включая сжатые
данные и образы с дополнительными устройствами. Исходный образ не изменяется;
создание и запись не поддерживаются. Нужен поставляемый динамический runtime
с EROFS-модулем; standalone `7zz` не содержит этого расширения.
[Происхождение, границы metadata и проверки](upstream-port-audit/erofs-linux.md).

Составной Linux initramfs читается через Cpio в поставляемом динамическом
runtime: поддерживаются смешанные raw/compressed части и hard links через
границы сжатия. Это расширение относительно upstream 7zFM; standalone `7zz`
сохраняет отдельные compression wrappers и raw CPIO. Расширения compressor
по-прежнему открывают внешний поток; полный initramfs доступен как Cpio.
[Границы и проверенные платформы](upstream-port-audit/cpio-linux.md#composite-initramfs--2026-10-20).

NTFS-модуль читает Windows security descriptors через `$SII`, включая allocated
index nodes и sparse `$SDS`; отсутствие зеркальной копии не скрывает корректный
дескриптор. Чтение metadata не применяет ACL к host filesystem.

Динамический NTFS-модуль показывает reparse link targets и читает их через
стандартные streams/extraction. Junction переводится относительно пути записи
в образе по Linux NTFS3; именованные ADS остаются отдельными потоками.
Deduplicated-файлы явно не читаются, как в Linux. Standalone сохраняет прежнее
представление ссылок. [Scope и проверки](upstream-port-audit/ntfs-linux.md#reparse-links-и-dedup-read-restrictions--2026-10-20).

NTFS-модуль дополнительно показывает WSL owner IDs, POSIX mode и device metadata
из EA. Специальные inode доступны как metadata, без выдачи служебных DATA bytes
обычным файлом. Это расширение чтения относительно исходного 7zFM;
[source/runtime scope](upstream-port-audit/ntfs-linux.md#ea-и-wsl-inode-metadata--2026-10-20)
отделяет его от настройки прав на host и native kernel enforcement.

## Необходимые платформенные адаптации

| Область | Отличие и граница |
| --- | --- |
| Диалоги | Native fonts, button minima, chrome и scaling Qt могут менять размеры; группировка, состояния и доступность проверяются по [UI contracts](ui-layout-contracts.md) |
| Клавиатура и меню | На macOS команда выхода размещается в меню Sevenzip с Cmd+Q. Platform key mapping, Cocoa global menu и физический Control требуют native проверок; offscreen-проверка их не заменяет |
| Выбор файлов и системные окна | Native OS panels проверяются отдельно от widget dialogs |
| Файловая система | Links, junctions, ADS, security metadata и native namespaces зависят от ОС, файловой системы и прав |
| Associations | Изменения регистрации не подтверждают защищённый OS-выбор приложения по умолчанию; Apply/Cancel и отказы проверяются отдельно |
| External codecs и SFX | Нужен совместимый официальный runtime; standalone `7zz` имеет иной набор возможностей, см. [настройку runtime](development.md) |
| Поставка | Состав runtime и подпись описаны в [packaging/CI](ci.md); локальная relocation-проверка не подтверждает clean-OS установку |
| Имя приложения | Qt-приложение называется Sevenzip; на macOS поставляется как `Sevenzip.app`. Настройки хранятся под именем Sevenzip отдельно от исходного 7zFM |
