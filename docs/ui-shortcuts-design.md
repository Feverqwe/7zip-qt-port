# Горячие клавиши нового интерфейса

Статус: назначения внедрены в Qt-представление, 18 октября 2026.
Фактическая область проверок публикуется в [source audit](upstream-port-audit/ui-redesign.md).
По указанию пользователя текущая приёмка ограничена проверками внутри Qt;
физические EN/RU-раскладки остаются отложенными и не считаются проверенными.
Этот документ задаёт действующую схему сочетаний с сохранением исходных команд
и функциональных владельцев. История согласования — в
[архивном плане редизайна](archive/plans/ui-redesign-plan.md).

## Принципы

Основные действия доступны без функционального ряда/Fn. Стандартные операции
используют платформенные сочетания; специальные архивные действия — собственные.
macOS использует Command, Windows/Linux — Control, но механическая замена
модификатора не подходит для всех команд.

Ориентиры для macOS: [официальные сочетания Apple](https://support.apple.com/en-us/102650).
Для реализации стандартных действий использовать
[QKeySequence::StandardKey](https://doc.qt.io/qt-6/qkeysequence.html), где его
семантика совпадает с командой. Собственные назначения таблицы — решение проекта,
они не объявляются стандартом Apple, Windows или Linux.

## Основная схема

В таблице `⌫` — Backspace/Delete на клавиатуре Mac, `⇧` — Shift.
Команды работы с объектами действуют при фокусе в файловой панели. Редактор,
поле пути, текст отчёта и модальное окно сохраняют собственные сочетания.

| Действие | macOS | Windows / Linux |
| --- | --- | --- |
| Открыть архив через выбор файла | ⌘O | Ctrl+O |
| Открыть выбранный объект | ⌘↓ | Enter |
| Переименовать | Return | F2 |
| Создать папку | ⌘⇧N | Ctrl+Shift+N |
| Добавить в архив… | ⌘⇧A | Ctrl+Shift+A |
| Распаковать… | ⌘⇧E | Ctrl+Shift+E |
| Тестировать архив | ⌘⇧T | Ctrl+Shift+T |
| Копировать в папку… | ⌘⇧C | Ctrl+Shift+C |
| Переместить в папку… | ⌘⇧M | Ctrl+Shift+M |
| Копировать в буфер | ⌘C | Ctrl+C |
| Вставить из буфера | ⌘V | Ctrl+V |
| Выделить всё | ⌘A | Ctrl+A |
| Удалить выбранное | ⌘⌫ | Delete |
| Свойства выбранного | ⌘I | Alt+Enter |
| Перейти к строке пути | ⌘L | Ctrl+L |
| На уровень вверх | ⌘↑ | Alt+↑ |
| Назад | ⌘[ | Alt+← |
| Обновить | ⌘R | Ctrl+R; F5 только в picker, где нет «Копировать в…» |
| Одна / две панели | ⌘⇧2 | Ctrl+Shift+2 |
| Настройки | ⌘, | Ctrl+, |
| Закрыть текущее окно | ⌘W | Ctrl+W |
| Выйти из приложения | ⌘Q | Платформенное Quit, включая Alt+F4 в Windows |

Сверка исходников уточнила первоначальное предположение концепта: кнопка Info
и пункт «Свойства» используют одну исходную команду IDM_PROPERTIES. Состав
сведений зависит от панели и выбора; отдельной команды информации об архиве
здесь нет. Сочетание регистрируется у пункта «Свойства», toolbar показывает
его в подсказке, не создавая вторую регистрацию. Просмотр, редактирование, создание файла,
комментарий, разделение, объединение, хеши и редкие режимы остаются доступны
через меню. Не каждой команде требуется новое буквенное сочетание.

На macOS Return переименовывает только объект в файловой панели; в форме он
сохраняет подтверждение, а в редакторе — ввод. Двойной щелчок продолжает открывать.
`⌘O` сохраняет существующий выбор архива; открытие выделенного — отдельная команда.
Не обещать Quick Look по Space: в проекте это отдельная неподтверждённая возможность.

Сочетание удаления вызывает исходный сценарий с исходными подтверждениями.
Оно не гарантирует корзину для архива или provider, который её не поддерживает.
Не добавлять обход подтверждения или новое безвозвратное удаление ради сочетания.
На macOS голый Backspace не должен удалять объект. `⌘⇧⌫` не назначать удалению:
в Finder это другая операция. Возможность явного удаления без корзины сохраняется
через действующий сценарий, но новый shortcut для неё здесь не назначается.

## Буфер, совместимость и зарезервированные клавиши

`⌘/Ctrl+C` копирует в буфер и не открывает «Копировать в папку…».
`⌘/Ctrl+V` вставляет в текущую панель по исходным правилам и возможностям.
`⌘/Ctrl+X` сохраняет поддерживаемое исходником поведение Cut; не подменять им
диалог перемещения и не обещать поддержку для неподходящего provider.
Не добавлять Finder-поведение `⌥⌘V` без отдельной проверки исходного clipboard-пути.

F2/F3/F4/F5/F6/F7/F9 можно сохранить как дополнительные сочетания соответствующих
исходных команд, если нет платформенного конфликта. В меню показывать основное
сочетание. Не создавать отдельную настройку «старые/новые клавиши» на этом этапе.
Существующие специальные варианты с Shift и команды выделения/закладок сверить
с исходными обработчиками: не терять их молча при переназначении.

Для синхронизации папок между панелями сохраняются Alt+Shift+Up и
Alt+Shift+Left/Right. В Windows/Linux Alt+Up и Alt+Left теперь выполняют
основную навигацию из таблицы. Ctrl/Command+Shift+2 имеет приоритет над прежним
сохранением закладки 2 через правый Control/Command; Alt+Shift+2 сохраняет
эту закладку, открытие через правый Control/Command+2 остаётся доступным.
Совместимый Backspace без Command сохраняет переход к родителю; на macOS
Command+Backspace выполняет удаление с исходным подтверждением.
Явное удаление без корзины на macOS доступно через исходное действие с Shift,
без назначения Command+Shift+Backspace. Ввод имени и обычные диалоги сохраняют
свои Return/Enter; переименование по Return/Enter относится только к списку.

`⌘/Ctrl+Z` освободить от команды «Комментарий». Это зарезервировано для Undo
в редактируемом тексте; освобождение не означает добавление отмены файловых
операций. Не занимать обычные Save, Find, New window/tab и системные сочетания
посторонними действиями. Существующий `⌘/Ctrl+N` для создания файла убрать;
создание файла остаётся в меню и через совместимый Shift+F4 при отсутствии конфликта.
Режимы представления и редкие исходные сочетания, не затронутые таблицей,
сохраняются до отдельной проверки, а не переназначаются наугад.

## Как внедрять и проверять

Это изменение Qt-представления ввода. Исходные обработчики операций не переписывать.
Перед внедрением сравнить upstream `resource.rc`, `PanelKey.cpp`, обработчики
списка/адреса и текущие Qt-адаптеры целиком в затронутом сценарии. Проверить
`QAction`, `ShortcutOverride`, panel key dispatch и контекстные копии действий:
изменение одной надписи меню не меняет всю фактическую маршрутизацию.

Применять назначения в одном месте на границе команд/представления. Меню,
контекстное меню и toolbar получают сочетание из одного источника. Использовать
NativeText для нативного отображения. Учесть, что Qt ControlModifier на macOS
соответствует Command; не выполнять второе ручное преобразование.

При нажатии должна выполниться ровно одна команда с правильной активной панелью.
Ввод и редактирование текста должны сохранять Copy/Paste/Cut/Undo, выделение,
Return и Backspace. В диалоге не должны срабатывать фоновые команды главного окна.
Проверить disabled-команды, одну/две панели, вложенный диалог и возврат фокуса.
Воспроизводимые конфликты покрыть поведением, а не сравнением списка строк.

Проверить реальные EN/RU раскладки и клавиатуру без отдельного F-ряда, отдельно
на каждой ОС. Не строить обработку на печатном `event.text()` или переводе названия
буквы. Для Linux проверить назначения в используемой desktop environment.
До такой проверки таблица — проект назначения, а не свидетельство отсутствия
всех runtime-конфликтов. Изменение относительно Windows 7zFM записать в parity
и затронутые контракты при фактическом внедрении.
