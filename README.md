# Sevenzip Desktop

Кроссплатформенный перенос интерфейса Windows 7-Zip File Manager на Qt Widgets для Windows, macOS и Linux. Структура окна и сценарии работы следуют оригиналу; адаптации под ОС описываются отдельно. UI и интеграционный код живут в этом Git-репозитории; официальный движок 7-Zip находится в отдельном соседнем checkout `../7zip-upstream`.

Цель — прямой перенос исходного кода upstream. Берём оригинальные реализации с сохранением относительных путей, имён файлов, классов и функций. UI-части адаптируем к Qt Widgets; остальную логику заимствуем с минимальными изменениями для кроссплатформенности и интеграции. Новая реализация с тем же поведением не заменяет перенос исходника. Соседний `7zip-upstream` остаётся неизменным: копии и адаптации размещаются в этом репозитории.

Текущий MVP содержит собственную логику, которую предстоит заменить upstream-кодом по мере переноса соответствующих частей. Происхождение кода и долг переноса описаны в [ревизии исходников](docs/upstream-port-audit.md). Форматы и сжатие сейчас обеспечивает официальный `7zz` через `ArchiveBackend`; эта граница сохраняется при переносе. Отличия поведения и платформ отмечаем в [сверке с 7zFM](docs/7zfm-parity.md).

При смене уровня сжатия метод и его ручные параметры сбрасываются к исходным значениям 7zFM; лимит памяти остаётся выбранным.

## Состояние проекта

Работает первый MVP на C++17 и Qt 6 Widgets. Приложение запускает официальный `7zz` через отдельный backend без shell. Подробная [сверка с 7zFM](docs/7zfm-parity.md), граница UI и движка — в [архитектуре](docs/architecture.md).

## Возможности MVP

- В списке цифровые `+`/`−` выделяют или снимают выделение по маске, Shift с ними — для всех записей, Alt — по типу текущей записи; цифровая `*` инвертирует выделение. Клавиши работают во всех четырёх режимах просмотра файловой системы и архива.
- При запуске окно показывает текущий каталог. Alt+F1 или Alt+F2 из списка файлов либо поля адреса раскрывают историю адресов; Tab из поля адреса возвращает фокус в текущий режим списка. Редактируемый выпадающий адрес принимает путь к папке или `.7z`/`.zip` и хранит до 20 посещённых каталогов, корней и внутренних папок архивов между запусками. **Вид → История папок…** (Alt+F12) открывает список, позволяет удалить записи и перейти к выбранной папке или архиву. Двойной щелчок открывает папку или архив из списка. **Назад** возвращает в предыдущую папку, а из архива — в папку, из которой его открыли.
- Меню **Избранное** сохраняет до 10 папок файловой системы или путей внутри архивов между запусками. При фокусе таблицы Alt+Shift+цифра сохраняет текущую папку, Alt+цифра открывает её. Недоступный каталог или файл архива оставляет текущую папку без изменений; если внутренняя папка архива исчезла, открывается ближайшая существующая родительская папка.
- Панель команд повторяет две группы 7zFM: **Добавить**, **Извлечь**, **Тест** и **Копировать**, **Переместить**, **Удалить**, **Информация**. Кнопки используют нарисованные в Qt цветные значки по мотивам оригинальных bitmap-ресурсов. Через **Вид → Панели инструментов** можно скрыть каждую группу, включить крупные значки или убрать подписи; выбор сохраняется. **Добавить** создаёт архив в каталоге или добавляет файлы в открытый архив; **Назад** и **Вверх** находятся рядом с адресной строкой.
- Когда таблица в фокусе, Enter открывает выбранную папку, архив или файл; Backspace, в том числе с Ctrl/Shift/Alt при фокусе списка, поднимает на уровень файловой системы или архива, а из корня архива возвращает в исходный каталог. Ctrl+A на Windows/Linux или Cmd+A на macOS выделяет все строки. Ctrl/Cmd+O открывает диалог выбора архива. Обычные файлы каталога открываются системным приложением. Файл архива сначала извлекается через backend во временную папку и затем открывается системным приложением; временная копия хранится до закрытия окна. Изменения этой копии пока не записываются обратно в архив.
- F3 открывает текстовый просмотр одного файла UTF-8 размером до 16 МиБ, в том числе из архива. F4 редактирует обычный файл или файл открытого незашифрованного `.7z`/`.zip`: после сохранения временной копии предлагает обновить архив, записывает изменение через backend и перечитывает список. Отмена или ошибка обновления сохраняет исходный архив. Двоичные файлы, файлы больше 16 МиБ и F4 во вложенном архиве недоступны; в оригинальном 7zFM F3/F4 могут запускать внешние программы.
- В меню **Файл** команды **Создать папку…** (F7) и **Создать файл…** (Ctrl+N или Shift+F4 при фокусе списка) создают объекты в текущем каталоге. Меню **Правка** позволяет выделить всё, снять или инвертировать выделение, а также выделять и снимать выделение по маске или типу текущего файла. **Вид → Обновить** (Ctrl+R) перечитывает текущий каталог или открытый архив, сохраняя текущую папку архива и сохранившееся выделение.
- **Файл → Открыть** открывает `.7z`, `.zip`, `.rar`, `.tar`, `.gz`/`.gzip`/`.tgz`, `.bz2`/`.bzip2`, `.xz`/`.txz`, `.zst`, `.cab`, `.iso` и `.wim`; путь к архиву можно передать первым аргументом приложения. При явном открытии файла, в том числе через адрес или «Открыть внутри», неизвестное расширение передаётся `7zz` для определения формата по содержимому; обычный двойной щелчок по такому файлу запускает системное приложение. Для форматов кроме `.7z` и `.zip` доступны просмотр, тест и извлечение, но не изменение. Поддержка содержимого определяется установленным `7zz`.
- **Открыть внутри** (Ctrl+PgDn) открывает выбранную папку или `.7z`/`.zip` как содержимое панели; вложенный архив сначала извлекается во временную папку, затем в нём можно переходить по папкам и извлекать файлы. **Назад** из корня вложенного архива возвращает к родительскому архиву и выделяет прежнюю запись. **Открыть снаружи** (Shift+Enter) запускает выбранный файл системным приложением, в том числе архивный файл после извлечения. Команды доступны также в контекстном меню. Вложенные архивы доступны только для чтения: их изменение не записывается обратно в родительский архив; временная копия удаляется при возврате. Закладка на временный путь вложенного архива не создаётся.
- В архиве таблица показывает текущую папку: двойной щелчок по папке открывает её, **Вверх** поднимает на уровень, а **Назад** поднимает на уровень или возвращает к исходному каталогу из корня архива. Двойной щелчок по файлу распаковывает только его и открывает системным приложением. Пустые и промежуточные папки видны в дереве; полный путь длинного имени доступен в подсказке.
- Таблица показывает имя, размер, сжатый размер в архиве и дату изменения. Полный путь хранится в данных строки и подсказке, но скрыт как столбец. Контекстное меню заголовка позволяет показывать и скрывать доступные столбцы свойств; выбор сохраняется. Щелчок по заголовку сортирует столбец; можно выделить несколько строк. **Извлечь выбранное** передаёт точные пути файлов и содержимое выбранных папок.
- **Сервис → Настройки…** открывает часть страницы Settings оригинального 7zFM: системные значки файлов, линии сетки и открытие одним щелчком. При открытии одним щелчком Ctrl/Shift и платформенный Meta сохраняют жесты множественного выделения. Параметры применяются сразу после подтверждения и сохраняются между запусками. Отмена не меняет список.
- **Вид** позволяет сортировать список по имени, типу, дате и размеру или вернуть исходный порядок элементов (Ctrl+F3–F7). Повторный выбор свойства меняет направление; размер, сжатый размер и дата сначала сортируются по убыванию. Папки остаются перед файлами в обоих направлениях. Свойство и направление сохраняются при переходе между папками и обновлении архива в текущем окне.
- **Вид** переключает крупные значки, мелкие значки, список и подробности (Ctrl+1–4). Режим сохраняется между запусками; выделение и команды работают с теми же файлами в каждом режиме.
- **Вид → Плоский вид** показывает файлы и папки вложенных каталогов в общем списке с относительными путями. Для файловой системы и архива настройка сохраняется отдельно, как в 7zFM. Выделение при переключении сохраняется, а операции используют полные пути объектов. Сортировка сравнивает имя файла, а для одинаковых имён — путь папки. Вложенный каталог заполняется порциями: во время сканирования можно перейти в другую папку или выключить плоский вид.
- **Извлечь** извлекает всё; **Файл → Извлечь выбранное** извлекает выделенные строки. Диалог следует расположению элементов 7zFM: редактируемая история папок (до 16 записей), выбор папки, полные пути или извлечение без путей, отказ от перезаписи, пропуск, перезапись либо переименование извлекаемого или существующего файла при конфликте, поле пароля с переключателем видимости. Родительская папка и имя подпапки задаются отдельно с флажком по образцу 7zFM. Флажок, режимы путей/перезаписи и видимость поля пароля сохраняются при подтверждении; сам пароль не сохраняется. Новая папка назначения создаётся при извлечении. Проверка конфликтов для выбранного извлечения касается только выбранных записей. При извлечении без путей совпадающие имена из разных папок отклоняются до запуска `7zz`.
- **Тест** проверяет открытый архив через `7zz t` без извлечения, включая пустой архив. Прогресс, отмена, ошибки и итог доступны в журнале; команда недоступна во время других операций.
- **Файл → CRC** рассчитывает CRC-32, CRC-64, XXH64, MD5, SHA-1, SHA-256, SHA-384, SHA-512, SHA3-256, BLAKE2sp или все суммы для выделенных файлов и папок. В архиве выбранные записи безопасно извлекаются во временную папку перед расчётом. Результаты 7zz показываются в журнале; операцию можно отменить.
- **Информация** показывает формат и физический размер только при наличии этих свойств в успешном ответе `7zz`, а также число файлов и папок и суммарный исходный размер файлов из списка. Если свойство отсутствует, это явно указано.
- **Создать…** в режиме файловой системы открывает единый диалог выбора файлов и папок. Выделенные в таблице объекты уже включены; в диалоге можно собрать источники из разных каталогов, указать имя, формат `.7z` или `.zip` и папку сохранения. Новый архив появляется по конечному пути только после успешной сборки; отмена и ошибка убирают временный файл.
- Диалог создания по образцу Add to Archive в 7zFM задаёт уровень и метод сжатия для `.7z` или `.zip` по таблицам upstream `CompressDialog.cpp`, потоки с исходными пределами CPU/метода и Auto по памяти, оценки расхода памяти и пользовательский лимит (Auto 80% RAM, проценты или размер) с сохранением отдельно для 7z/ZIP, размер словаря LZMA/LZMA2 по исходному ряду от 64 КиБ и память PPMd для 7z и ZIP, словарь BZip2 100–900 КиБ и размер слова (набор размеров слова взят из 7zFM: LZMA 8–273, ZIP Deflate 8–258 и Deflate64 8–257; порядок PPMd: 7z 2–32, ZIP 2–16), а также Auto, Non-solid, Full solid и размеры непрерывного блока от 1 МиБ до 64 ГиБ по исходному ряду 7zFM для `.7z`. Уровень, метод, словарь, слово, solid, потоки и лимит памяти сохраняются отдельно для 7z/ZIP при OK; отмена не меняет профиль. Пока не перенесены тома, SFX и режимы обновления. Можно выбрать шифрование: для `.7z` AES-256 с открытыми или скрытыми именами файлов, для `.zip` AES-256 с паролем из ASCII (локальный `7zz` отклоняет Unicode пароль ZIP). Пароль нужно ввести дважды; оба поля можно показать. При открытии защищённых заголовков, проверке и извлечении `7zz` запрашивает пароль в отдельном поле. Неверный пароль показывается как ошибка; перед извлечением защищённый архив проверяется, чтобы неверный пароль не оставил файл в папке назначения. Пароль передаётся процессу через stdin, не сохраняется в настройках и после открытия хранится только до закрытия или повторного открытия архива.
- **Файл → Добавить в открытый архив…** выбирает файлы и папки для открытого `.7z` или `.zip`. Диалог показывает неизменяемые имя, формат и путь цели. Совпадающие имена, включая различия регистра и формы Unicode, отклоняются без перезаписи. Backend обновляет копию архива и заменяет исходный файл лишь после успеха; затем окно перечитывает содержимое. Ошибка и отмена сохраняют исходный архив.
- **Файл → Разбить файл… / Объединить файлы…** работают с одним обычным файлом. Разделение задаёт папку и размер части или последовательность размеров (например, `10M 20M`, где последний размер повторяется), создаёт `.001`, `.002` и далее; объединение по первой части восстанавливает файл. Как в 7zFM, принимаются числовые суффиксы `01`, `001` и длиннее, в том числе без точки перед номером. Перед сборкой диалог показывает число частей, общий размер и имена первых и последней частей. Операции выполняются в фоне с отменой, не перезаписывают существующие файлы и убирают временный вывод при ошибке.
- **Копировать** (F5) переносит выбранные файлы и папки между обычными каталогами без перезаписи; из архива эта команда извлекает выбранные записи в существующую папку. **Переместить** (F6) работает между обычными каталогами и из открытого незашифрованного архива в папку. Копирование и перемещение между каталогами идут в рабочем потоке: диалог показывает текущий файл и позволяет отменить операцию; временная копия и уже опубликованные объекты убираются при ошибке или отмене. Перемещение между томами пока не поддерживается. При переносе из архива сначала извлекаются выбранные записи; только после успеха они удаляются из архива и список перечитывается. Отмена или ошибка извлечения не меняет архив. Если удаление не удалось, извлечённые файлы остаются в папке, а исходные — в архиве. Общий диалог Copy/Move показывает выбранные имена, позволяет выбрать папку кнопкой и хранит до 20 введённых назначений между запусками. Отмена диалога назначения ничего не меняет; конфликт имени или ошибка показываются пользователю. В файловой системе можно также **Удалить** (Delete, с подтверждением) и **Переименовать** (F2). После операции список каталога обновляется.
- В открытом незашифрованном архиве **Удалить** удаляет выбранные файлы или папки с содержимым после подтверждения; **Переименовать** доступно для одного файла или папки. Обе команды меняют временную копию архива и перечитывают список после успеха. Ошибка запуска `7zz` и отмена сохраняют исходный архив. Для зашифрованного архива эти команды отключены.
- Файлы файловой системы можно перетащить из таблицы в другое приложение и в текущий каталог; перетаскивание локальных файлов в открытый незашифрованный архив запускает добавление. Контекстное меню таблицы учитывает выделение и режим каталога или архива; из него доступны свойства выделенных объектов. Пустая область предлагает создание папки или добавление в архив и обновление. Перетаскивание всегда копирует источник.
- **Свойства…** доступны и для нескольких выбранных записей: диалог показывает число файлов и папок, сумму размеров выбранных файлов и, внутри архива, их сжатый размер. Для папок архива учитываются все вложенные файлы; пересекающиеся выделения не удваивают сумму. Для папок файловой системы рекурсивный размер пока не вычисляется.
- Операции `7zz` показывают название, процент и текущий файл или действие, допускают отмену и не блокируют окно во время работы процесса. В меню **Файл → Журнал последней операции…** доступен текстовый вывод `7zz` и итог, включая ошибки и отмену. Журнал обновляется во время работы и заменяется при запуске следующей операции.
- Во время загрузки и операции команды навигации, открытия, создания, добавления, копирования, перемещения, удаления, переименования, выделения, извлечения, теста и информации недоступны. Повторное открытие очищает прежний список; ошибка запуска `7zz` или отмена открытия возвращает к каталогу. После отмены создания обновляется список текущего каталога и команда снова доступна. После ошибки или отмены изменения открытый архив остаётся доступен; после успеха команды включаются после перечитывания списка. Пустой архив допускает добавление, тест и просмотр информации, но не предлагает действия с выделением.

Перемещение в архив, прямое копирование между архивами и перетаскивание из архива наружу пока недоступны. Папки в открытом незашифрованном `.7z` или `.zip` можно переименовать, включая неявные папки без отдельной записи в архиве. Добавление в защищённый архив отключено; при обычном добавлении запрещены ссылки и совпадающие пути, а добавление в уже существующую папку архива требует отдельного сценария и пока отклоняется. Для изменения нужен свободный объём как минимум под копию архива; подготовка этой копии сейчас выполняется в потоке UI. Файловые операции не перезаписывают существующие имена и не следуют по ссылкам; при ошибке список обновляется, а уже завершённые удаления нескольких объектов могут остаться выполненными. Перед полным извлечением проверяются все записи архива, а перед выбранным — только извлекаемые записи: абсолютные пути, `.` и `..`, ссылки, непереносимые имена, дубликаты с учётом регистра и Unicode, а также конфликт файла с вложенной папкой блокируют операцию. Папка назначения должна существовать и сама не быть ссылкой; ссылки внутри неё на путях извлечения также отклоняются. По умолчанию существующий файл блокирует извлечение; в диалоге можно выбрать пропуск или перезапись обычного файла. Перезапись выполняется непосредственно `7zz` и при ошибке или отмене может оставить частично изменённый файл. Проверка выполняется до запуска `7zz`; одновременное изменение архива или папки другим процессом между проверкой и записью пока не защищено. `7zz` должен находиться в `PATH`; на macOS также проверяются стандартные пути Homebrew. Проверка на Windows и Linux ещё не проводилась.

## Быстрый старт

Установите CMake, Ninja, Qt 6 Widgets, `clang-format` и официальный `7zz`. На macOS:

```sh
brew install cmake ninja qtbase sevenzip clang-format
```

Из корня репозитория:

```sh
sh .agents/skills/sevenzip-setup/scripts/setup.sh
./scripts/doctor.sh
./scripts/check.sh
```

`check.sh` проверяет формат C++, собирает приложение и запускает CTest. Тесты Qt сохраняют снимки трёх размеров окна, папки внутри архива, диалогов создания и добавления и журнала в `build/dev/ui-screenshots/`; автоматического сравнения снимков пока нет. Подробности по Windows, Linux и macOS — в [инструкции разработки](docs/development.md). О тестовой стратегии см. [тестирование](docs/testing.md).

На macOS запустите `build/dev/sevenzip_desktop.app`. Для открытия архива из терминала: `build/dev/sevenzip_desktop.app/Contents/MacOS/sevenzip_desktop /path/to/archive.7z`.

## Агент и Obsidian

Агент читает локальный индекс `.codex/memory/README.md` в начале проектной задачи и сохраняет полезные исследования и передачи работы в `.codex/notes/`. [Протокол памяти](docs/agent-memory.md) задаёт проверку устаревших выводов, разделение параллельных задач и перенос устойчивых фактов в `docs/`. Память доступна новым чатам в этом checkout; через Git она автоматически не переносится.

Для проверки компоновки агент использует [текстовые спецификации окон и геометрию Qt](docs/ui-layout-contracts.md). Тест `ui_geometry` создаёт JSON-отчёты; скриншоты нужны только для вопросов, которые текст и геометрия не объясняют.

`AGENTS.md` задаёт правила для агента: менять код и документацию, добавлять регрессионные тесты для поведения и доводить задачи до проверенного результата. Повторяемые проектные навыки лежат в `.agents/skills/`:

- `$sevenzip-setup` — создаёт или обновляет локальную среду, Obsidian vault и Git-хук;
- `$sevenzip-context` — находит и поддерживает знания о проекте;
- `$sevenzip-navigation` — прослеживает код UI, адаптера и оригинального 7-Zip;
- `$sevenzip-cpp-qt` — помогает писать C++17 и Qt Widgets, подключать `7zz` и соблюдать границы компонентов;
- `$sevenzip-regression` — добавляет тесты и проверяет изменения.

Скрипт настройки создаёт игнорируемую Git папку `.codex/`. Откройте **`<repo>/.codex` как vault** в Obsidian: «Open folder as vault», затем выберите скрытую папку через `Command-Shift-G` на macOS. В vault ссылки на актуальные `README.md`, `AGENTS.md` и `docs/`; локальные заметки и вложения сохраняются в `.codex/notes/` и `.codex/attachments/`. Повторный запуск настройки их не удаляет. В самой Obsidian можно открыть стартовую страницу командой:

```sh
open "obsidian://open?path=$(python3 -c 'from pathlib import Path; from urllib.parse import quote; print(quote(str(Path(".codex/Home.md").resolve()), safe=""))')"
```

После настройки локальный pre-commit хук запускает `check.sh` перед коммитом. GitHub Actions повторит проверки на macOS, Linux и Windows после публикации репозитория на GitHub. Сейчас удалённый репозиторий не настроен, поэтому CI ещё не выполнялся.
