# Sevenzip Desktop

Кроссплатформенный графический интерфейс в духе классического 7-Zip File Manager для Windows, macOS и Linux.

## Репозитории

```text
~/git/
├── sevenzip-desktop/   # наш UI и интеграционный код
└── 7zip-upstream/      # официальный исходный код ip7z/7zip
```

Исходники 7-Zip не копируются в наш репозиторий. Оба каталога имеют независимую историю Git. Путь к соседнему checkout не зашит в приложение.

## Стек

C++17, Qt 6 Widgets и CMake. Qt Widgets подходит для меню, панелей инструментов, таблицы файлов и диалогов в стиле Windows-версии 7-Zip. Архивные операции планируется сначала подключить через официальный `7zz`, сохранив возможность перейти к прямой интеграции кода 7-Zip.

## Быстрый старт

Установите зависимости для своей ОС по [инструкции разработки](docs/development.md), затем:

```sh
./scripts/doctor.sh
./scripts/build.sh dev
ctest --preset dev --output-on-failure
```

Если Qt установлен не через Homebrew, задайте путь к нему вручную:

```sh
CMAKE_PREFIX_PATH=/path/to/Qt/6.x/your-platform ./scripts/build.sh dev
```

## Состояние

Создан каркас окна с панелью команд и таблицей файлов. Команды пока отключены; чтение архивов не подключено. Дальнейшие задачи — в [плане](docs/roadmap.md). Граница UI и архивного движка описана в [архитектуре](docs/architecture.md). Правила для работающего над проектом агента — в [AGENTS.md](AGENTS.md).

## Лицензии

7-Zip имеет собственные лицензии; подробности в соседнем `7zip-upstream/DOC/License.txt`. У Qt Widgets доступны открытые лицензии LGPLv3/GPLv2 и коммерческая лицензия. Лицензию нашего UI нужно выбрать до публикации или распространения сборок.
