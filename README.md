# Sevenzip Desktop

Кроссплатформенный графический интерфейс в духе классического 7-Zip File Manager для Windows, macOS и Linux.

## Структура каталогов

```text
~/git/
├── sevenzip-desktop/   # наш UI и интеграционный код; отдельный Git-репозиторий
└── 7zip-upstream/      # официальный исходный код ip7z/7zip; отдельный Git-репозиторий
```

Исходники 7-Zip не копируются в наш репозиторий. Его версия и лицензия остаются независимыми. Путь к соседнему checkout не зашит в проект.

## Техническое направление

- Язык: C++17, как у оригинального ядра.
- UI: Qt 6 Widgets — классические окна, меню, панели инструментов и таблицы.
- Сборка: CMake.
- На первом этапе: UI и отдельный адаптер к официальному `7zz` для операций. Позже можно оценить прямое подключение библиотек 7-Zip, если консольный интерфейс ограничит функциональность.
- Windows-интерфейс 7-Zip служит функциональным ориентиром; платформенные детали адаптируются под macOS и Linux.

## Текущее состояние

Создан каркас окна с панелью команд и таблицей файлов. Команды пока отключены; чтение архивов не подключено.

## Сборка

Понадобятся Qt 6 с модулем Widgets, CMake и компилятор C++17:

```sh
cmake -S . -B build
cmake --build build
```
