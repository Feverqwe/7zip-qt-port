# Sevenzip Desktop

Кроссплатформенный перенос Windows 7-Zip File Manager на C++17 и Qt 6 Widgets
для Windows, macOS и Linux. Цель — перенос исходного кода с адаптацией UI;
архивные форматы и сжатие обеспечивает официальный `7zz`.

## Состояние проекта

Работает первый MVP: навигация по файловой системе и архивам, история и
избранное, четыре режима списка и плоский вид, выделение и сортировка,
создание и изменение `.7z`/`.zip`, извлечение, тест и контрольные суммы.
Доступны файловые операции, Split/Combine, свойства, текстовый просмотр
и редактирование с обновлением файла в незашифрованном верхнем архиве.
Операции показывают прогресс и журнал и поддерживают отмену.
Добавление файлов в открытый архив использует перенесённый modal ProgressDialog:
подтверждение отмены, Pause/Continue, Background/Foreground и сообщения об ошибках.
Пауза управляет принадлежащим backend процессом `7zz`; остальные progress consumers
ещё переносятся по P0-10.2.
Свойства используют текущего владельца папки и исходные индексы элементов;
неизвестные значения пропускаются, упакованный размер показан и для файловой
системы. Время файловой системы и архивов отображается через исходный
formatter с настройкой точности и UTC; выдача `7zz` ограничивает доступную
точность архивных значений. Остальные метаданные остаются в плане.
Две дисковые панели переключаются F9 и Tab, сохраняют раздельные путь, режим
списка и выбор; команды адресуются активной панели. Обе обновляются при изменении
каталога и сохраняют выбор и прокрутку; на macOS/Linux используется опрос
метаданных, архив обновляется вручную. Смешанные пары с архивом, восстановление
разделителя после запуска и назначение второй панели для Copy/Move остаются в
P0-08.2/P1-01.
Создание архивов сохраняет историю путей и профили параметров; доступны AES-256
для 7z и AES-256/ZipCrypto для ZIP. Запрос пароля использует перенесённый
PasswordDialog с переключателем показа. Пароли не сохраняются.
Параметры списка используют исходные SettingsPage и CFmSettings: элемент «..»,
значки, выделение всей строки, сетку, один щелчок с hover, альтернативное
выделение с отметками и системное меню. Остальные страницы настроек пока
отсутствуют.

Вложенные архивы доступны для чтения. Прямое копирование между архивами,
перемещение в архив и перетаскивание из архива наружу пока недоступны.
Проверки на одной ОС не подтверждают работу на остальных платформах.

## Быстрый старт

Установите CMake, Ninja, Qt 6 Widgets, `clang-format` и официальный `7zz`. На macOS:

```sh
brew install cmake ninja qtbase sevenzip clang-format
```

Из корня репозитория:

```sh
sh .agents/skills/sz-setup/scripts/setup.sh
./scripts/doctor.sh
./scripts/check.sh
```

`check.sh` проверяет формат C++, собирает приложение и запускает CTest.
На macOS запустите `build/dev/sevenzip_desktop.app`. Для открытия архива
из терминала: `build/dev/sevenzip_desktop.app/Contents/MacOS/sevenzip_desktop /path/to/archive.7z`.
`7zz` должен находиться в `PATH`; на macOS также проверяются стандартные пути Homebrew.

## Агент и локальная память

Проектные навыки находятся в `.agents/skills/`: `sz-setup`, `sz-context`,
`sz-navigation`, `sz-cpp-qt`, `sz-regression` и `sz-ui-parity`.
Настройка создаёт игнорируемый Git vault `.codex/` со ссылками на документацию,
локальными заметками и вложениями; повторный запуск их сохраняет.
Эту папку можно открыть как vault в Obsidian (на macOS скрытый путь доступен
через Command-Shift-G). Порядок работы описан в
[протоколе памяти](docs/agent-memory.md).

7-Zip имеет собственные лицензии; текст для перенесённых фрагментов сохранён
в [third_party/7zip/License.txt](third_party/7zip/License.txt), исходник —
в `../7zip-upstream/DOC/License.txt`. У Qt Widgets доступны открытые лицензии
LGPLv3/GPLv2 и коммерческая лицензия. Лицензию нашего UI нужно выбрать до
распространения сборок.
