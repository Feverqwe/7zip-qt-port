# Sevenzip Desktop

Кроссплатформенный перенос интерфейса Windows 7-Zip File Manager на Qt Widgets для Windows, macOS и Linux. Структура окна и сценарии работы следуют оригиналу; адаптации под ОС описываются отдельно. UI и интеграционный код живут в этом Git-репозитории; официальный движок 7-Zip находится в отдельном соседнем checkout `../7zip-upstream`.

## Состояние проекта

Работает первый MVP на C++17 и Qt 6 Widgets. Приложение запускает официальный `7zz` через отдельный backend без shell. Подробная [сверка с 7zFM](docs/7zfm-parity.md), граница UI и движка — в [архитектуре](docs/architecture.md).

## Возможности MVP

- При запуске окно показывает текущий каталог. Редактируемый выпадающий адрес принимает путь к папке или `.7z`/`.zip` и хранит до 20 посещённых каталогов и корней архивов за текущий сеанс; двойной щелчок открывает папку или архив из списка. **Назад** возвращает в предыдущую папку, а из архива — в папку, из которой его открыли.
- Меню **Избранное** сохраняет до 10 папок файловой системы или путей внутри архивов между запусками. При фокусе таблицы Alt+Shift+цифра сохраняет текущую папку, Alt+цифра открывает её. Недоступный каталог или файл архива оставляет текущую папку без изменений; если внутренняя папка архива исчезла, открывается ближайшая существующая родительская папка.
- Панель команд повторяет две группы 7zFM: **Добавить**, **Извлечь**, **Тест** и **Копировать**, **Переместить**, **Удалить**, **Информация**. Кнопки используют нарисованные в Qt цветные значки по мотивам оригинальных bitmap-ресурсов. Через **Вид → Панели инструментов** можно скрыть каждую группу, включить крупные значки или убрать подписи; выбор сохраняется. **Добавить** создаёт архив в каталоге или добавляет файлы в открытый архив; **Назад** и **Вверх** находятся рядом с адресной строкой.
- Когда таблица в фокусе, Enter открывает выбранную папку или архив; Backspace поднимает на уровень файловой системы или архива, а из корня архива возвращает в исходный каталог. Ctrl+A на Windows/Linux или Cmd+A на macOS выделяет все строки. Ctrl/Cmd+O открывает диалог выбора архива. Обычные файлы внутри архива и неподдерживаемые файлы в каталоге клавишей Enter пока не открываются.
- В меню **Файл** команда **Создать папку…** (F7) создаёт папку в текущем каталоге. Меню **Правка** позволяет выделить всё, снять или инвертировать выделение. **Вид → Обновить** (Ctrl+R) перечитывает текущий каталог или открытый архив, сохраняя текущую папку архива и сохранившееся выделение.
- **Файл → Открыть** открывает `.7z` и `.zip`; путь к архиву можно передать первым аргументом приложения.
- В архиве таблица показывает текущую папку: двойной щелчок по папке открывает её, **Вверх** поднимает на уровень, а **Назад** поднимает на уровень или возвращает к исходному каталогу из корня архива. Файл внутри архива двойным щелчком пока не открывается. Пустые и промежуточные папки видны в дереве; полный путь длинного имени доступен в подсказке.
- Таблица показывает имя, размер, сжатый размер в архиве и дату изменения. Полный путь хранится в данных строки и подсказке, но скрыт как столбец. Контекстное меню заголовка позволяет показывать и скрывать доступные столбцы свойств; выбор сохраняется. Щелчок по заголовку сортирует столбец; можно выделить несколько строк. **Извлечь выбранное** передаёт точные пути файлов и содержимое выбранных папок.
- **Извлечь** извлекает всё; **Файл → Извлечь выбранное** извлекает выделенные строки. Диалог позволяет указать или выбрать существующую папку и заранее сообщает, что пути внутри архива сохраняются, а существующие файлы не перезаписываются. Проверка конфликтов для выбранного извлечения касается только выбранных записей.
- **Тест** проверяет открытый архив через `7zz t` без извлечения, включая пустой архив. Прогресс, отмена, ошибки и итог доступны в журнале; команда недоступна во время других операций.
- **Информация** показывает формат и физический размер только при наличии этих свойств в успешном ответе `7zz`, а также число файлов и папок и суммарный исходный размер файлов из списка. Если свойство отсутствует, это явно указано.
- **Создать…** в режиме файловой системы открывает единый диалог выбора файлов и папок. Выделенные в таблице объекты уже включены; в диалоге можно собрать источники из разных каталогов, указать имя, формат `.7z` или `.zip` и папку сохранения. Новый архив появляется по конечному пути только после успешной сборки; отмена и ошибка убирают временный файл.
- В диалоге создания можно выбрать шифрование: для `.7z` AES-256 с открытыми или скрытыми именами файлов, для `.zip` AES-256 с паролем из ASCII (локальный `7zz` отклоняет Unicode пароль ZIP). При открытии защищённых заголовков, проверке и извлечении `7zz` запрашивает пароль в отдельном поле. Неверный пароль показывается как ошибка; перед извлечением защищённый архив проверяется, чтобы неверный пароль не оставил файл в папке назначения. Пароль передаётся процессу через stdin, не сохраняется в настройках и после открытия хранится только до закрытия или повторного открытия архива.
- **Файл → Добавить в открытый архив…** выбирает файлы и папки для открытого `.7z` или `.zip`. Диалог показывает неизменяемые имя, формат и путь цели. Совпадающие имена, включая различия регистра и формы Unicode, отклоняются без перезаписи. Backend обновляет копию архива и заменяет исходный файл лишь после успеха; затем окно перечитывает содержимое. Ошибка и отмена сохраняют исходный архив.
- **Копировать** (F5) переносит выбранные файлы и папки между обычными каталогами без перезаписи; из архива эта команда извлекает выбранные записи в существующую папку. **Переместить** (F6) работает только между обычными каталогами. Отмена диалога назначения ничего не меняет; конфликт имени или ошибка показываются пользователю. В файловой системе можно также **Удалить** (Delete, с подтверждением) и **Переименовать** (F2). После операции список каталога обновляется.
- В открытом незашифрованном архиве **Удалить** удаляет выбранные файлы или папки с содержимым после подтверждения; **Переименовать** доступно для одного файла. Обе команды меняют временную копию архива и перечитывают список после успеха. Ошибка запуска `7zz` и отмена сохраняют исходный архив. Для зашифрованного архива эти команды отключены.
- Файлы файловой системы можно перетащить из таблицы в другое приложение и в текущий каталог; перетаскивание локальных файлов в открытый незашифрованный архив запускает добавление. Контекстное меню таблицы учитывает выделение и режим каталога или архива; из него доступны свойства одного выбранного объекта. Пустая область предлагает создание папки или добавление в архив и обновление. Перетаскивание всегда копирует источник.
- Операции `7zz` показывают название, процент и текущий файл или действие, допускают отмену и не блокируют окно во время работы процесса. В меню **Файл → Журнал последней операции…** доступен текстовый вывод `7zz` и итог, включая ошибки и отмену. Журнал обновляется во время работы и заменяется при запуске следующей операции.
- Во время загрузки и операции команды навигации, открытия, создания, добавления, копирования, перемещения, удаления, переименования, выделения, извлечения, теста и информации недоступны. Повторное открытие очищает прежний список; ошибка запуска `7zz` или отмена открытия возвращает к каталогу. После отмены создания обновляется список текущего каталога и команда снова доступна. После ошибки или отмены изменения открытый архив остаётся доступен; после успеха команды включаются после перечитывания списка. Пустой архив допускает добавление, тест и просмотр информации, но не предлагает действия с выделением.

Перемещение из архива и в архив, прямое копирование между архивами, переименование папки внутри архива и перетаскивание из архива наружу пока недоступны. Добавление в защищённый архив отключено; при обычном добавлении запрещены ссылки и совпадающие пути, а добавление в уже существующую папку архива требует отдельного сценария и пока отклоняется. Для изменения нужен свободный объём как минимум под копию архива; подготовка этой копии и копирование больших файлов между каталогами сейчас выполняются в потоке UI. Файловые операции не перезаписывают существующие имена и не следуют по ссылкам; при ошибке список обновляется, а уже завершённые удаления нескольких объектов могут остаться выполненными. Перед полным извлечением проверяются все записи архива, а перед выбранным — только извлекаемые записи: абсолютные пути, `.` и `..`, ссылки, непереносимые имена, дубликаты с учётом регистра и Unicode, а также конфликт файла с вложенной папкой блокируют операцию. Папка назначения должна существовать; конечная папка не может быть ссылкой, а существующие файлы, ссылки и совпадающие имена не перезаписываются. Проверка выполняется до запуска `7zz`; одновременное изменение архива или папки другим процессом между проверкой и записью пока не защищено. `7zz` должен находиться в `PATH`; на macOS также проверяются стандартные пути Homebrew. Проверка на Windows и Linux ещё не проводилась.

## Быстрый старт

Установите CMake, Ninja, Qt 6 Widgets, `clang-format` и официальный `7zz`. На macOS:

```sh
brew install cmake ninja qtbase sevenzip clang-format
```

Из корня репозитория:

```sh
sh .agents/skills/sevenzip-setup/scripts/setup.sh
./scripts/doctor.sh
./scripts/check.sh
```

`check.sh` проверяет формат C++, собирает приложение и запускает CTest. Тесты Qt сохраняют снимки трёх размеров окна, папки внутри архива, диалогов создания и добавления и журнала в `build/dev/ui-screenshots/`; автоматического сравнения снимков пока нет. Подробности по Windows, Linux и macOS — в [инструкции разработки](docs/development.md). О тестовой стратегии см. [тестирование](docs/testing.md).

На macOS запустите `build/dev/sevenzip_desktop.app`. Для открытия архива из терминала: `build/dev/sevenzip_desktop.app/Contents/MacOS/sevenzip_desktop /path/to/archive.7z`.

## Агент и Obsidian

`AGENTS.md` задаёт правила для агента: менять код и документацию, добавлять регрессионные тесты для поведения и доводить задачи до проверенного результата. Повторяемые проектные навыки лежат в `.agents/skills/`:

- `$sevenzip-setup` — создаёт или обновляет локальную среду, Obsidian vault и Git-хук;
- `$sevenzip-context` — находит и поддерживает знания о проекте;
- `$sevenzip-navigation` — прослеживает код UI, адаптера и оригинального 7-Zip;
- `$sevenzip-cpp-qt` — помогает писать C++17 и Qt Widgets, подключать `7zz` и соблюдать границы компонентов;
- `$sevenzip-regression` — добавляет тесты и проверяет изменения.

Скрипт настройки создаёт игнорируемую Git папку `.codex/`. Откройте **`<repo>/.codex` как vault** в Obsidian: «Open folder as vault», затем выберите скрытую папку через `Command-Shift-G` на macOS. В vault ссылки на актуальные `README.md`, `AGENTS.md` и `docs/`; локальные заметки и вложения сохраняются в `.codex/notes/` и `.codex/attachments/`. Повторный запуск настройки их не удаляет. В самой Obsidian можно открыть стартовую страницу командой:

```sh
open "obsidian://open?path=$(python3 -c 'from pathlib import Path; from urllib.parse import quote; print(quote(str(Path(".codex/Home.md").resolve()), safe=""))')"
```

После настройки локальный pre-commit хук запускает `check.sh` перед коммитом. GitHub Actions повторит проверки на macOS, Linux и Windows после публикации репозитория на GitHub. Сейчас удалённый репозиторий не настроен, поэтому CI ещё не выполнялся.
