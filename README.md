# Sevenzip Desktop

Кроссплатформенный перенос Windows 7-Zip File Manager на C++17 и Qt 6 Widgets
для Windows, macOS и Linux. Цель — перенос исходного кода с адаптацией UI;
архивные форматы и сжатие обеспечивает официальный движок 7-Zip.

Для Linux/Windows проверок настроены общие x64 Hyper-V runners с отдельными
snapshot Sevenzip и сборкой официального движка из закреплённой ревизии. Команды и ограничения:
[Hyper-V runners](docs/hyperv-runners.md).

подключены к Options; Linux GIO и macOS NSWorkspace имеют native adapters.

числа источников. Замена файла и исходный Add-план обновляют эти семь форматов

## Состояние проекта

Работает первый MVP: навигация по файловой системе и архивам, история и
избранное, четыре режима списка и плоский вид, выделение и сортировка,
создание и изменение `.7z`/`.zip`, извлечение, тест и контрольные суммы.
Для открытого верхнего ZIP/7z диалог Add предлагает исходные режимы
Add/Update/Freshen/Synchronize, параметры сжатия и Relative/Full/Absolute
режимы путей. Add в защищённый верхний ZIP/7z сохраняет защиту архива;
Synchronize сохраняет выбранные исходным update planner дочерние записи.
При создании ZIP/7z можно задать размеры архивных томов с исходными presets;
номера начинаются с `.001`, поддерживаются пароль и отмена без частичных outputs.
Для этого требуется место для полного временного архива и томов. Проверка
source UI открывает первый `.001`, проверяет выбранные элементы либо весь архив
и извлекает через общий Ask callback. Повреждённые/отсутствующие тома и неверный
пароль показывают ошибки; изменение набора томов отключено.
Команда «Удалить временные файлы» открывает исходный temp browser с Qt controls;
удаление требует подтверждения и допускается только для owned объектов в OS temp.
Активные сеансы и копии с неподтверждённым завершением внешнего приложения защищены.
При первой ошибке удаление останавливается; Refresh сохраняет оставшееся выделение.
В Add доступны исходная форма дополнительных параметров, точность и сохранение
времени файлов, строка параметров метода и отдельные профили ZIP/7z. Отмена
не сохраняет изменения. Можно установить время самого архива по последнему
элементу и удалить неизменившиеся обработанные исходники после успешной
публикации. Удаление доступно в Add и по умолчанию выключено; отмена до публикации
сохраняет исходники. Preserve access и shared writing доступны на Windows.
Реальные RAR decoder RAM prompts остаются обязательным P1-18.
Доступны файловые операции, Split/Combine, свойства, текстовый просмотр
и редактирование с обновлением файла в незашифрованном верхнем архиве.
Создание папки принимает составной путь; F2 переименовывает объект прямо в
списке с Enter/Escape. Delete перемещает объекты в системную корзину,
Shift+Delete удаляет постоянно после подтверждения.
Архивные, файловые и томовые операции используют перенесённый ProgressDialog:
статистику, диагностические сообщения, подтверждение отмены и фоновый приоритет.
Пауза управляет принадлежащим backend процессом `7zz`; для файловых и томовых
workers Split/Combine она отключена до появления реальной worker capability;
создание архивных томов поддерживает паузу. Последние
сообщения открываются через исходный MessagesDialog.
Свойства используют текущего владельца папки и исходные индексы элементов;
неизвестные значения пропускаются, упакованный размер показан и для файловой
системы. Время файловой системы и архивов отображается через исходный
formatter с настройкой точности и UTC; выдача `7zz` ограничивает доступную
точность архивных значений. Остальные метаданные остаются в плане.
Две дисковые панели переключаются F9 и Tab, сохраняют раздельные путь, режим
списка и выбор; команды адресуются активной панели. Обе обновляются при изменении
каталога и сохраняют выбор и прокрутку; на macOS/Linux используется опрос
метаданных, архив обновляется вручную. Смешанные пары диск/архив и архив/архив,
восстановление панелей и разделителя, Alt+F1/F2 и путь второй панели в
Copy/Move/Extract поддерживаются. F5/F6 между дисковыми панелями, из архива
на диск и с диска в открытый верхний ZIP/7z обновляют обе панели. F5 из
архива использует общий CopyDialog и пути текущей папки; F5/F6 с диска в
архив используют исходный CopyFrom/update и пароль открытого архива.
F5/F6 между двумя открытыми верхними ZIP/7z проходят исходный temp staging;
F6 откатывает цель при отмене удаления источника. Исходный `CApp::OnCopy`
ведёт обычные F5/F6 и Shift+F5/F6 для элемента под фокусом. Одиночный
destination filename копирует или перемещает объект под новым именем;
из архива Shift извлекает элемент в указанную папку.
Перетаскивание в обоих видах панелей использует исходные правила Copy/Move,
выбор подпапки и подтверждение копирования в архив. Внешний файловый drop
открывает Add. При drag-out из архива реальные данные готовятся до передачи;
временные копии удерживаются, если завершение внешнего получателя неизвестно.
Нативная проверка Finder остаётся отдельным обязательным P3-03.1;
проверки Explorer и Linux file manager также ещё не выполнены.
Конфликты имён при файловом Copy/Move обрабатывает исходный OverwriteDialog:
Да/Нет, решения для всех, автоматическое переименование и отмена; прежняя
цель сохраняется до успешного завершения всей операции. При совпадении папок
совпадающие папки сливаются; вложенные файлы отдельно спрашивают решение,
а пропущенные файлы при F6 остаются в источнике.
Если F6 между томами не может перенести источник через rename, рабочий поток
копирует его во временную цель и удаляет только после публикации. Ошибка
удаления показывает частичный результат и сохраняет опубликованные байты.
При извлечении Ask использует тот же диалог. Целый архив, в том числе вложенный
или многотомный, проходит исходные `ExtractGUI`/`Extract` и общий callback;
выбранные объекты и текущая папка проходят исходный `CPanel::CopyTo`.
`7zz` поставляет байты файлов, а исходный callback запрашивает решение перед
перезаписью. Пароль проверяется до открытия занятой цели.
Извлечение пишет прямо в папку назначения, поэтому ошибка или отмена может
оставить уже созданные файлы.
Создание архивов сохраняет историю путей и профили параметров; доступны AES-256
для 7z и AES-256/ZipCrypto для ZIP. Запрос пароля использует перенесённый
PasswordDialog с переключателем показа. Пароли не сохраняются.
Параметры списка используют исходные SettingsPage и CFmSettings: элемент «..»,
значки, выделение всей строки, сетку, один щелчок с hover, альтернативное
выделение с отметками и переключатель системного меню. Сами shell-команды
контекстного меню пока отключены до платформенной интеграции. Главное меню и
toolbar используют исходный порядок 7zFM и bitmap-ресурсы; четыре поля
состояния принадлежат каждой панели. В настройках доступны страницы «Папки»,
«7-Zip», «Редактор», «Настройки», «Язык» и System. Принятый P2-08: System
показывает source association catalog; изменения выполняются только по Apply,
недоступные native scopes/types отключены с причиной. Windows UserChoice
сохраняется; macOS/Linux требуют установленного native application handler.
Полные Windows/Linux gates и установленная native регистрация остаются P3. Исходные English
и Russian переключают меню, toolbar, список, status, Options и остальные текущие
формы без потери выделения и введённых значений. Сообщения операций получают
явный EN/RU-контекст, сохраняя пути и текст движка; fallback и клавиатурная
доступность проверены на macOS. Windows/Linux runtime ещё не проверен. На странице
«7-Zip» Windows поддерживает перенос Zone.Identifier при FM extraction;
shell registration, Cascaded/Icons/ElimDup и flags отключены до P2-09. Можно выбрать
рабочую папку и сохранить лимит RAM для распаковки; настоящие decoder prompts
ещё требуют отдельной engine-интеграции. Большие страницы памяти доступны в Windows.
Apply обновляет обе панели, Cancel сохраняет уже применённые значения. F3/F4 обычного файла
запускают настроенные внешние viewer/editor, Diff использует настроенную программу
сравнения и исходные правила двух панелей. На macOS/Linux пустой viewer использует
системное приложение, editor требует настройки. Архивные F3/F4 извлекают файл во
временную папку и отслеживают внешний процесс и его дочерние процессы. После
правки исходный диалог предлагает обновить архив; при ошибке правка сохраняется
во временном файле. Ограниченный текстовый просмотр/правка доступны отдельными
пунктами меню. Исходный VerCtrl хранит резервные версии и поддерживает
Edit/Commit/Revert/Diff; команды появляются для одного файла при настроенных
Diff и каталоге `FM/7vc` в INI, как у upstream.

F1 и кнопки справки открывают исходные offline-разделы 7-Zip26.03 с внутренними
ссылками и якорями. Справка английская; окно, навигация и ошибки имеют EN/RU
контекст. «О 7-Zip» показывает исходные версию/дату, лицензию и сайт; версия
Sevenzip Desktop указана отдельно от исходников и внешнего `7zz`. Очистка
временных файлов пока отключена до переноса owned-temp lifetime.

Свойства перечисляют доступные item/folder/archive данные и контрольные суммы.
Длинный текст можно открыть целиком или скопировать; undefined значения не
подменяются нулём. Данные, не представленные в выводе `7zz`, не выдумываются.

F3 для выбранных папок файловой системы считает полный размер и число вложенных
объектов, обновляя список и сводку выделения. Пустая папка показывает ноль.

Вложенные ZIP/7z поддерживают исходную обратную запись: после изменения
внутреннего архива возврат в родителя предлагает обновить внешний архив.
No/Cancel отклоняют изменения; ошибка записи сохраняет изменённую временную
копию. Все уровни должны поддерживать запись; TAR/GZip и наборы томов остаются
доступными для чтения. Дополнительный встроенный text editor во вложенном
архиве отключён; используйте исходную команду F4 с внешним редактором.
Перетаскивание из архива наружу пока недоступно.
Проверки на одной ОС не подтверждают работу на остальных платформах.

## Быстрый старт

Установите CMake, Ninja, Qt 6 Widgets, `clang-format` и официальный `7zz`. На macOS:

```sh
brew install cmake ninja qtbase sevenzip clang-format
```

Из корня репозитория:

```sh
sh .agents/skills/sz-setup/scripts/setup.sh
./scripts/doctor.sh
./scripts/check.sh
```

`check.sh` проверяет формат C++, собирает приложение и запускает CTest.
На macOS запустите `build/dev/sevenzip_desktop.app`. Для открытия архива
из терминала: `build/dev/sevenzip_desktop.app/Contents/MacOS/sevenzip_desktop /path/to/archive.7z`.
`7zz` должен находиться в `PATH`; на macOS также проверяются стандартные пути Homebrew.

Для текущей интеграции внешних кодеков P2-02 на macOS/Linux можно подготовить
официальный dynamic runtime командой `./scripts/build-codec-runtime.sh`.
На Windows используйте `scripts/build-codec-runtime.ps1 -Architecture arm64`
в соответствующем Visual Studio developer environment; доступны также x64/x86.
Debug-сборка использует созданные `build/codec-runtime/7z` и `7z.so`;
`SEVENZIP_ENGINE_PATH` явно выбирает другой engine. Standalone `7zz` служит
резервным вариантом. P2-02 ещё не принят полностью; детали и ограничения —
в [development](docs/development.md) и [source audit](docs/upstream-port-audit.md).

## Агент и локальная память

Проектные навыки находятся в `.agents/skills/`: `sz-setup`, `sz-context`,
`sz-navigation`, `sz-cpp-qt`, `sz-regression` и `sz-ui-parity`.
Настройка создаёт игнорируемый Git vault `.codex/` со ссылками на документацию,
локальными заметками и вложениями; повторный запуск их сохраняет.
Эту папку можно открыть как vault в Obsidian (на macOS скрытый путь доступен
через Command-Shift-G). Порядок работы описан в
[протоколе памяти](docs/agent-memory.md).
